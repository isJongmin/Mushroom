# 버섯마을

여러 사용자가 웹에서 각자의 아바타로 만나 대화하는 멀티플레이 웹게임. 메이플스토리를 벤치마킹한다.

## 현재 범위
- 아바타 커스터마이징
- 닉네임 (중복 불가)
- 계정당 캐릭터 1개
- 맵에서 말풍선 대화

## 향후 계획
- 전직: 전사, 도적, 궁수, 마법사
- 몬스터 사냥

## 기술 스택
- 호스팅: GitHub Pages (정적)
- 백엔드: Supabase (DB, 인증, Realtime)
- 프런트: 바닐라 JS + Canvas 2D, 빌드 도구 없음 (docs/ARCHITECTURE.md)
- 아트: 마인크래프트풍 블록 픽셀아트 PNG (원본은 assets/_src/block/ 생성 스크립트)

## 공통 규칙
- 비밀 키(service_role 등)는 저장소와 프런트 코드에 넣지 않는다.
- 데이터 접근은 RLS 정책을 통해서만 허용한다.
- 설계 결정은 docs/ARCHITECTURE.md에 기록한다.
- 역할별 쓰기 범위는 docs/ROLES.md를 따른다.
