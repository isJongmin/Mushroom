# 버섯마을

여러 사용자가 웹에서 각자의 아바타로 만나 대화하는 멀티플레이 웹게임. 메이플스토리를 벤치마킹한다.

## 현재 범위 (사이클 4: 로그인 없는 채팅방)
- 로그인 없음: 닉네임을 정하고 캐릭터를 꾸민 뒤 바로 입장 (익명 계정, 프로필은 브라우저에 저장)
- 채팅방: 방 만들기(비밀번호 선택), 방 목록, 잠금 방 비밀번호 입장, 방당 20명, 빈 방 30분 후 정리
- 방 안: 같은 맵에서 캐릭터로 이동, 말풍선 + 채팅 로그(최근 50개 보관)
- 닉네임 중복은 같은 방 안에서만 금지

## 협동 사냥과 직업 (2026-10-29)
- 플레이어끼리 피해를 주지 않는 협동 사냥. 몬스터 접촉 피해는 유지.
- 프로필에서 검사·궁수·마법사·도적 선택. 근접 베기 / 이동 화살 / 마력탄 범위 폭발 / 이동 표창.
- 몬스터 처치 후 재생성 간격 10초. 모자는 프레임별 헤어 클리핑 적용.
- 세부 구현과 검증: docs/handoff/gameplay-20261029-jobs-coop.md

## 기술 스택
- 호스팅: GitHub Pages (정적)
- 백엔드: Supabase (DB, 인증, Realtime)
- 프런트: 바닐라 JS + Canvas 2D, 빌드 도구 없음 (docs/ARCHITECTURE.md)
- 아트: 3D 복셀 모델 조명 렌더 PNG/WebP. 캐릭터는 assets/_src/voxel/(variety.py 포함), 현재 몬스터는 assets/_src/voxel_mob/. assets/_src/art2d_mob/는 과거 2D 원본이며 현재 몬스터 빌드에 사용하지 않는다.

## 공통 규칙
- 비밀 키(service_role 등)는 저장소와 프런트 코드에 넣지 않는다.
- 데이터 접근은 RLS 정책을 통해서만 허용한다.
- 설계 결정은 docs/ARCHITECTURE.md에 기록한다.
- 역할별 쓰기 범위는 docs/ROLES.md를 따른다.
