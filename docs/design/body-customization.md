# 캐릭터 체형 커스터마이징 v2

## 화면과 동작

캐릭터 생성/수정 화면을 `01 체형 / 02 코디`로 나눈다. 왼쪽은 게임에서 쓰는 아바타 렌더러로 앞/옆/뒤와 걷기를 미리 보여준다. 체형 탭에는 균형·동화·날렵·든든 프리셋, 세부 슬라이더 9개, 체형 초기화 버튼을 제공한다. 프리셋 썸네일도 현재 코디와 실제 체형을 사용한다. 모바일에서는 슬라이더를 아래로 스크롤하는 동안 작은 캐릭터 미리보기를 상단에 고정해 변경 결과를 함께 볼 수 있게 한다. 프리셋을 적용한 뒤 세부 수치를 바꾸면 `직접 조정`으로 표시한다. 체형 변경은 코디를 유지하고 코디 변경도 체형을 유지한다.

범위는 원본 비율 대비 백분율이며 100%가 기본이다. 키보드로 1%씩 조절할 수 있다. 체형 초기화는 비율만 100%로 복원한다. 코디 탭의 `처음 모습`은 화면에 들어왔을 때의 외형과 체형으로 돌아간다. 취소하면 기존 프로필은 변경되지 않는다.

| 항목 | 키 | 범위 | 실제 반영 |
|---|---|---|---|
| 머리 크기 | head | 10–200% | 머리 영역 가로·세로 및 얼굴/머리카락/모자 함께 |
| 다리 길이 | legLength | 10–200% | 발 기준점 고정, 하체 길이와 상체 높이 |
| 어깨·팔 너비 | shoulders | 10–200% | 어깨 높이의 전체 가로 폭, 소매/팔 포함 |
| 가슴 너비 | chest | 10–200% | 가슴 높이의 전체 가로 폭, 상의 포함 |
| 허리 너비 | waist | 10–200% | 허리 높이의 전체 가로 폭 |
| 골반 너비 | hips | 10–200% | 골반 높이의 전체 가로 폭 |
| 허벅지 너비 | thighs | 10–200% | 허벅지 높이의 전체 가로 폭 |
| 종아리 너비 | calves | 10–200% | 종아리 높이의 전체 가로 폭 |
| 발 너비 | feet | 10–200% | 신발 영역의 가로 폭 |

이 구현은 2D 합성 시트의 높이별 폭을 부드럽게 변형하는 방식이다. 독립적인 3D 두께나 관절 변형이 아니다. 같은 높이에 있는 팔/긴 머리/의상 끝도 함께 변한다. 엎드리기와 공격 같은 기울어진 자세에서도 같은 연속 변형을 적용한다. 팔 길이·손 크기·눈·코·입 크기의 독립 슬라이더는 제공하지 않는다. 얼굴은 기존 표정 파츠를 선택한다. 이 항목을 추가하려면 부위 마스크나 분리된 관절/얼굴 원본부터 준비해야 한다.

## 게임·저장·동기화

- 기존 7개 코디 키를 유지하고 프로필에 별도 `body` 객체를 저장한다. 과거 프로필/누락/비정상 필드는 기본 100%로 복원하고 숫자는 범위 제한·정수화한다.
- 체형은 로컬 프로필과 방 입장 Presence에만 추가한다. DB 스키마나 인증/권한은 변경하지 않는다. 전투/이동 메시지에는 체형을 매번 넣지 않는다. 구버전 클라이언트는 새 체형을 기본 비율로 보므로 최신 외형을 보려면 새로고침이 필요하다.
- 렌더러 내부 체형 메타데이터는 Symbol 키를 사용해 기존 avatar JSON 7개 키 계약과 분리한다. 코스튬을 적용하는 object spread에는 유지된다.
- 기본 시트 합성 후 전체 13프레임을 한 번 변형해 기존 LRU에 보관한다. 프레임별 픽셀 변형은 하지 않는다. 기본 체형은 변형을 건너뛰어 픽셀이 원본과 동일하다.
- 10–200% 변형 시 원본 프레임을 벗어나는 좌표까지 포함하는 가변 크기·기준점 시트를 만든다. 미리보기는 넘칠 때만 축소해 전체를 보여주며 게임 내 월드 크기는 선택한 비율을 유지한다. 큰 시트의 좌우 반전은 그리기 변환으로 처리해 복제 메모리를 피한다. 시트 캐시는 48개 및 128MiB 한도로 정리한다.
- 투명색 번짐과 프레임 간 오염을 피하도록 프레임 내부에서 알파를 가중해 보간한다. 손/무기 부착점도 같은 좌표 변환을 적용한다. 망토 목/밑단과 이름표 높이를 변형된 외형에 맞춘다.
- 슬라이더 드래그 미리보기는 100ms 단위로 합치고 놓으면 즉시 최신 값을 반영한다. 합성 중에는 마지막 완성된 캐릭터를 유지한다. 타이머·이벤트·캐시는 화면 종료 시 해제한다.
- 피격 범위·플랫폼 충돌·사다리·공격 판정·사거리·능력치는 체형을 읽지 않는다.

## 검증

`node tests/body-profile-flow.test.mjs`: 실제 프로필 화면 마운트, 탭 전환, 미리보기 지연 전에 저장, 코디 독립 유지, 다시 열기, 취소, 초기화, 타이머 해제.

`node tests/avatar-body.test.mjs`: 비정상 값, 이전 저장 호환, Presence 정규화, 기본 픽셀 유지, 프레임 경계 오염 방지, 실제 아바타 4프리셋×13프레임, 손 부착점, 20캐릭터 캐시 렌더 시 20 drawImage, 프리셋/슬라이더/초기화/이벤트 해제.

v1에서는 브라우저 제어 기능이 없어 반응형 레이아웃·터치 조작과 운영 Supabase 세션 동기화를 확인하지 못했다. v2의 자동 검증은 네이티브 Canvas 및 DOM 픽스처 기반이며, 운영 Supabase 세션과 모바일 실기기 검증은 별도로 필요하다. 네이티브 Canvas로 실제 원본을 렌더링해 여러 코디와 공격 자세를 시각 확인했다.

## 무기 가림 개선

장착 무기 전용 도형을 분리해 검날·지팡이·클로·활·방패의 가로 폭과 장식을 줄인다. 검과 지팡이는 대기/이동 때 가로에 가까운 각도로 들고 공격 프레임은 기존 손 중심 회전을 유지한다. 고등급 날개·왕관·주변 파티클은 장착 그림에서 제외하고 인벤토리/드롭 아이콘의 풍부한 실루엣은 유지한다. 작은 체형은 무기도 축소하며 큰 체형에서 무기를 더 키우지는 않는다. 피해량·판정은 변경하지 않는다.

`node tests/compact-held-weapons.test.mjs`: 25종 무기/등급 장착 도형의 불투명 면적이 아이콘 대비 최소 35% 감소, 검/지팡이 가로 대기 자세, 작은 체형의 무기 축소.
