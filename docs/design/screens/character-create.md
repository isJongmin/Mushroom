# 화면 설계: 캐릭터 생성

참조: `docs/design/style-guide.md` (파츠 id 목록 5.4, 아바타 규격 5장, 색 1장). 저장 값은 `characters.avatar` 형식 `{ "skin", "hair", "eyes", "top", "bottom" }`.

## 1. 목적과 진입

- 계정당 캐릭터 1개. 캐릭터가 없는 계정만 이 화면에 들어온다.
- 진입 경로: 회원가입 성공, 캐릭터 없는 계정으로 로그인.
- 완료 후: 인게임 (`game.md`)으로 이동.
- 이 화면을 떠나는 방법: "로그아웃" 링크 (로그인 화면으로). 캐릭터가 있는 계정이 이 화면에 들어오는 경우는 없다.

## 2. 레이아웃

### 2.1 데스크톱 (720px 이상)

2열 구성. 전체 카드 가로 720px, 패딩 24px, 열 사이 간격 24px.

| 열 | 가로 | 내용 (위 -> 아래) |
|---|---|---|
| 왼쪽 (미리보기) | 280px | 미리보기 박스 (높이 336px) -> 닉네임 필드 + 상태 줄 -> 만들기 버튼 |
| 오른쪽 (파츠) | 가로 나머지 (416px) | 파츠 행 5개 (피부, 머리, 눈, 상의, 하의) |

- 제목 "캐릭터 만들기": `fs-lg` 20px 굵기 700, 카드 최상단, 아래 24px.
- 상단 우측: "로그아웃" 텍스트 버튼 (`fs-sm`, `secondary-text`, 44 x 44 터치 영역).

### 2.2 모바일 (720px 미만, 최소 360px)

세로 한 열. 카드 가로 = 뷰포트 - 32px. 패딩 16px.

순서 (위 -> 아래):
1. 제목 "캐릭터 만들기" + 우측 "로그아웃"
2. 미리보기 박스 (높이 264px, 가운데 정렬)
3. 닉네임 필드 + 상태 줄
4. 파츠 행 5개 (각 행 높이 56px)
5. 만들기 버튼 (가로 100%, 높이 48px). 화면 하단에 붙임 (`position: sticky; bottom: 16px`)

가로 스크롤 금지. 360px 폭에서 파츠 행의 좌/우 버튼 44px + 값 글자가 한 줄에 들어가야 한다. 값 글자가 길면 말줄임 (`…`).

## 3. 미리보기

| 항목 | 데스크톱 | 모바일 |
|---|---|---|
| 박스 크기 | 가로 280px, 높이 336px | 가로 100%, 높이 264px |
| 아바타 표시 크기 | 3배 = 192 x 288 화면 px | 2.5배 = 160 x 240 화면 px |
| 배경 | 위쪽 `sky-top` -> `sky-bottom` 그라데이션 + 하단 잔디 띠 (`grass` 40px) | 같음 |
| 박스 모서리 | `radius-lg` 12px, 테두리 1.5px `border` | 같음 |
| 기준점 위치 | 아바타 발바닥이 박스 하단에서 24px 위 | 같음 (20px 위) |

- 아바타는 `style-guide.md` 5장 규격 그대로 레이어 순서대로 합성한다 (skin, bottom, top, eyes, hair).
- 파츠를 바꾸면 즉시 다시 그린다. 애니메이션, 전환 효과 없음 (바꾸는 즉시 반영).
- 미리보기는 정지 포즈. 흔들림 없음.
- 미리보기는 클릭되지 않는다 (`aria-hidden="true"`, 대체 설명은 파츠 행의 값 글자가 담당).

## 4. 닉네임 입력

### 4.1 필드

| 항목 | 값 |
|---|---|
| 라벨 | "닉네임" (`fs-sm` 14px 굵기 700) |
| 입력 | 높이 44px, `fs-md` 16px, `maxlength="12"`, `autocomplete="off"`, `spellcheck="false"` |
| 허용 문자 | 한글 완성형 (가-힣), 영문 대소문자, 숫자 |
| 검사 정규식 | `^[가-힣a-zA-Z0-9]{2,12}$` |
| 도움말 (기본 상태) | "2~12자, 한글, 영문, 숫자만 사용할 수 있습니다." (`fs-xs` 12px `text-muted`) |

규칙:
- 한글 자모(ㄱ, ㅏ 등 조합 중이거나 낱자)는 완성형이 아니므로 형식 오류로 처리한다.
- 공백, 특수문자, 이모지 금지. 입력 시 공백을 막지 않고 형식 오류로 알린다.
- 대문자와 소문자는 구분하지 않고 중복 판단한다 (서버 기준). 클라이언트 중복 판단은 서버 응답에 따른다.
- 입력 값 앞뒤 공백은 제거하고 검사한다.

### 4.2 상태 줄 (닉네임 필드 아래, 높이 20px 고정)

상태 줄의 높이는 항상 20px로 고정해 상태가 바뀌어도 화면이 흔들리지 않는다.

| 상태 | 조건 | 글자 색 | 문구 | 아이콘 |
|---|---|---|---|---|
| 미확인 | 형식은 맞지만 아직 확인 안 함 | `text-muted` | "중복 확인이 필요합니다." | 없음 |
| 형식 오류 | 정규식 불일치 | `error` | "2~12자의 한글, 영문, 숫자만 사용할 수 있습니다." | 없음 |
| 확인 중 | 중복 확인 요청 중 | `text-muted` | "확인 중..." | 12px 스피너 |
| 사용 가능 | 서버 응답: 사용 가능 | `success` | "사용할 수 있는 닉네임입니다." | 체크 "✓" |
| 중복 | 서버 응답: 이미 사용 중 | `error` | "이미 사용 중인 닉네임입니다." | 없음 |
| 확인 실패 | 네트워크 또는 서버 오류 | `error` | "닉네임 확인에 실패했습니다. 다시 시도하세요." | 없음 |

필드 테두리:
- 기본 `border` 1.5px, 포커스 `secondary` + 3px `focus` 링 (투명도 40%).
- 형식 오류 또는 중복: 테두리 2px `error`, `aria-invalid="true"`.
- 사용 가능: 테두리 2px `success`.

### 4.3 중복 확인 시점

- 값이 형식에 맞고 입력이 500ms 멈추면 자동 확인 (디바운스 500ms).
- 필드에서 포커스가 떠날 때 (blur), 형식이 맞고 아직 현재 값으로 확인하지 않았다면 즉시 확인.
- 값이 바뀌면 상태는 "미확인"으로 돌아간다. 이전 결과를 현재 값에 재사용하지 않는다.
- 만들기 버튼을 눌렀을 때 상태가 "사용 가능"이 아니면 확인부터 하고, 사용 가능이면 바로 생성 요청을 보낸다.
- 확인 응답은 참고용이다. 최종 중복 판단은 생성 요청 시 서버가 한다 (`409` 같은 중복 응답 -> "중복" 상태).

## 5. 파츠 선택 UI

### 5.1 행 구성

| 순서 | 파츠 | 라벨 | 옵션 수 | 기본값 |
|---|---|---|---|---|
| 1 | skin | 피부 | 3 | `skin-light` |
| 2 | hair | 머리 | 4 | `hair-round-black` |
| 3 | eyes | 눈 | 3 | `eyes-dot` |
| 4 | top | 상의 | 3 | `top-tee-red` |
| 5 | bottom | 하의 | 3 | `bottom-shorts-navy` |

### 5.2 옵션 표시 이름 (값 글자)

| 파츠 | 옵션 순서 (왼쪽 -> 오른쪽) |
|---|---|
| 피부 | 밝은 피부 -> 보통 피부 -> 진한 피부 |
| 머리 | 둥근 단발 · 흑발 -> 둥근 단발 · 밤색 -> 뾰족 머리 · 흑발 -> 뾰족 머리 · 밤색 |
| 눈 | 점 눈 -> 큰 눈 -> 웃는 눈 |
| 상의 | 빨간 티셔츠 -> 파란 후드티 -> 초록 조끼 |
| 하의 | 네이비 반바지 -> 청바지 -> 분홍 치마 |

옵션 순서는 `style-guide.md` 5.6과 같다. 순서를 바꾸지 않는다.

### 5.3 행 규격

- 행 높이 56px (모바일), 64px (데스크톱). 행 사이 구분선 1px `border`.
- 왼쪽 라벨: `fs-sm` 14px 굵기 700, 가로 56px 고정.
- 이전 버튼 (◀), 다음 버튼 (▶): 44 x 44px 터치 영역, 모서리 `radius-md`, 테두리 1.5px `border-strong`, 배경 `#FFFFFF`, 아이콘 글자 `secondary-text`.
- 가운데 값: `fs-md` 16px, 가운데 정렬, 말줄임. 아래에 `fs-xs` 12px `text-muted`로 "2 / 4" 같은 순번 표시 (데스크톱만).
- 버튼 누름: 배경 `secondary-soft`.
- 키보드: 행에 포커스가 있을 때 좌/우 방향키로 이전/다음.
- 순환: 맨 앞에서 이전을 누르면 맨 뒤로, 맨 뒤에서 다음을 누르면 맨 앞으로.
- 버튼 `aria-label`: "이전 머리 모양", "다음 머리 모양" 식으로 파츠 라벨을 넣는다.
- 값 변경 시 `aria-live="polite"` 영역에 "머리: 뾰족 머리 · 흑발" 식으로 알린다.

### 5.4 동작

- 좌/우 누르면 옵션이 바뀌고 미리보기가 즉시 갱신된다.
- 길게 누르면 자동 반복은 없다 (MVP).
- 파츠 변경은 닉네임 상태에 영향을 주지 않는다.

## 6. 만들기 버튼

| 항목 | 값 |
|---|---|
| 라벨 | "캐릭터 만들기" |
| 활성 조건 | 닉네임 형식이 맞다 (상태가 형식 오류, 중복, 확인 실패이면 비활성) |
| 규격 | 가로 (데스크톱은 280px, 모바일은 100%), 높이 48px, `primary` 배경, `primary-text` 700, `shadow-btn` |
| 비활성 | 배경 `panel-alt`, 글자 `text-disabled` |

상태별 동작:

| 상태 | 버튼 | 표시 |
|---|---|---|
| 기본 (닉네임 비어 있음) | 비활성 | 상태 줄: "2~12자, 한글, 영문, 숫자만 사용할 수 있습니다." |
| 닉네임 입력 중 (형식 맞음, 미확인) | 활성 | 상태 줄: "중복 확인이 필요합니다." |
| 확인 중 | 활성 (누르면 확인이 끝난 뒤 생성) | 상태 줄: "확인 중..." |
| 사용 가능 | 활성 | 상태 줄: 성공 문구 |
| 중복 / 형식 오류 / 확인 실패 | 비활성 | 해당 문구 |
| 생성 중 | 비활성. 스피너 + "만드는 중..." | 닉네임 필드, 파츠 행, 로그아웃 모두 비활성 |
| 생성 실패 (네트워크) | 활성 | 카드 상단 오류 배너 (아래 7장) |
| 생성 실패 (닉네임 중복) | 활성 | 닉네임 상태 "중복". 버튼은 비활성 |
| 완료 | 비활성 | 인게임으로 페이드 전환 200ms |

## 7. 오류 문구

| 코드 | 상황 | 표시 위치 | 문구 |
|---|---|---|---|
| `NICK_FORMAT` | 닉네임 형식 오류 | 닉네임 상태 줄 | 2~12자의 한글, 영문, 숫자만 사용할 수 있습니다. |
| `NICK_TAKEN` | 닉네임 중복 (확인 또는 생성 응답) | 닉네임 상태 줄 | 이미 사용 중인 닉네임입니다. |
| `NICK_CHECK_FAILED` | 중복 확인 실패 | 닉네임 상태 줄 | 닉네임 확인에 실패했습니다. 다시 시도하세요. |
| `NETWORK` | 생성 요청 실패 (네트워크) | 카드 상단 배너 (`role="alert"`, 배경 `error-bg`, 글자 `error`) | 캐릭터를 만들지 못했습니다. 연결을 확인한 뒤 다시 시도하세요. |
| `SERVER` | 그 밖의 생성 실패 | 카드 상단 배너 | 캐릭터를 만들지 못했습니다. 잠시 후 다시 시도하세요. |

규칙:
- 생성 실패 후에도 입력한 닉네임과 파츠 선택은 유지된다.
- 배너는 다음 생성 요청 시 지운다.

## 8. 완료 흐름

1. 만들기 누름 -> 버튼 "만드는 중..." (비활성), 전체 입력 비활성.
2. 서버에 `nickname`과 `avatar`(5개 키) 저장 요청.
3. 성공 -> 화면 페이드 200ms -> 인게임 진입.
4. 실패 -> 7장 규칙대로 표시, 입력 복구.

저장 값 예시 (기본 조합):

```json
{ "nickname": "버섯이", "avatar": { "skin": "skin-light", "hair": "hair-round-black", "eyes": "eyes-dot", "top": "top-tee-red", "bottom": "bottom-shorts-navy" } }
```

## 9. 접근성

- 닉네임 필드는 `<label for>`로 연결한다. 상태 줄은 `aria-describedby`로 연결하고, 상태가 바뀌면 `aria-live="polite"`로 읽는다.
- 파츠 행은 `role="group"`과 라벨(`aria-labelledby`)로 묶는다.
- 미리보기는 `aria-hidden="true"`. 파츠 값 글자가 같은 정보를 전달한다.
- 모든 버튼 터치 영역 44px 이상. 포커스 링 3px `focus`.
- 색만으로 상태를 구분하지 않는다. 상태 줄의 문구와 아이콘(✓)을 함께 쓴다.
