# 화면 설계: 인게임 (맵 + HUD)

버전: 3.0 (2026-10-14, 사이클 3 블록 UI). 조작, 채팅 규칙, 접속자 수 규칙, 재연결 규칙, 접근성은 v1/v2와 같다. 바뀐 것: 1장 구성(HUD를 블록 CSS 컴포넌트로), 3장 모바일 조작 영역 124 → 132px, 6장 아바타 표시(블록 아트 계약 참조, 48x64 프레임), 7장 배너 모양, 10장 체크 항목.
참조: `docs/design/style-guide.md` v3 (배율과 카메라 6장, 라벨 7장, 말풍선 8장, 컴포넌트 5장), 구현 CSS `docs/design/ui-kit.css`. 아바타/맵 규격은 ARCHITECTURE "블록 아트 계약", 실시간 메시지는 ARCHITECTURE 4번 결정.
시안: `docs/design/ref/c3/game-desktop.png` (1280x800, 재연결 배너 표시 상태), `docs/design/ref/c3/game-mobile.png` (360x640, 왼쪽 버튼 눌림 상태). 시안 맵은 아트 샘플 장면이다.

## 1. 구성

| 영역 | 내용 | 구현 방식 |
|---|---|---|
| 게임 캔버스 | 맵 레이어, 발 그림자, 아바타, 닉네임 라벨, 말풍선 | Canvas 2D (style-guide 6장) |
| HUD (캔버스 위에 겹침) | 접속자 배지, LOCAL MODE 칩, 조작 힌트(데스크톱), 로그아웃, 상태 배너 | DOM. 캔버스와 같은 크기의 `.game-stage`(`position: relative`) 안에 `.hud`(`position: absolute`) |
| 채팅 입력 | 입력 + 글자 수, 전송 버튼(모바일) | DOM `.chat-row`, 캔버스 아래 |
| 터치 버튼 | 왼쪽 이동, 오른쪽 이동 (모바일) | DOM `.touch-row`, 캔버스 아래 |

채팅 기록 패널은 없다. 채팅은 말풍선으로만 보이고 저장하지 않는다 (ARCHITECTURE 4번).
페이지 바탕(캔버스 바깥)은 `--letterbox` (`ink`). HUD 요소는 바깥 계단 테두리 때문에 캔버스 가장자리에서 최소 8px 떨어뜨린다.

## 2. 데스크톱 레이아웃 (720px 이상)

세로 묶음 [캔버스 → 12px → 채팅 입력 행 → 16px]을 뷰포트 가운데에 둔다 (`.scr-game`).

| 요소 | 위치 | 규격 |
|---|---|---|
| 캔버스 | 묶음 맨 위 | style-guide 6.1: P=2이면 가로 `min(innerWidth, 1280)`, 세로 `min(540, innerHeight - 72)` (P의 배수로 내림). P=3 조건이면 최대 1920 x 810 |
| 접속자 배지 | 캔버스 왼쪽 위, 여백 12px (`.hud-l`) | `.bk-chip`: 버섯 도트 아이콘(16 x 14) + 4px + "접속 중 N명" 14px 700 `ink`. 박스 높이 28 |
| LOCAL MODE 칩 | 접속자 배지 오른쪽 8px, 세로 가운데 | `.bk-chip--mode` (style-guide 5.6). local 모드만 |
| 조작 힌트 | 캔버스 오른쪽 위, 로그아웃 왼쪽 8px (`.hud-r`) | `.bk-chip.bk-chip--hint`: 12px 700 `w3`. 내용 "← → 또는 A D 이동 · Enter 채팅 · Esc 입력 해제". 캔버스 가로 900px 미만이면 숨긴다 |
| 로그아웃 버튼 | 캔버스 오른쪽 위, 여백 12px | `.bk-btn.bk-btn--sm` (돌 블록, 높이 32, 14px) |
| 상태 배너 | 캔버스 위 가운데, 위에서 52px | 7장 |
| 채팅 입력 행 | 캔버스 아래 12px, 가운데 | `.chat-row` 가로 `min(560px, 화면 - 32px)`. 입력 박스 높이 44 |

HUD 요소는 캔버스 아래쪽 60px(지면 아래 흙, 닉네임 라벨 자리)에 두지 않는다.

### 2.1 채팅 입력 (데스크톱)

- `.bk-input.bk-input--with-end`: 가로 100%, 박스 높이 44px, 16px 400. 플레이스홀더 "메시지를 입력하세요" (`w3`).
- 글자 수 `.bk-counter`: 입력 오른쪽 안쪽(`.bk-input-end`), 형식 "N/80", 12px 700 `w3`. 입력 시작 후에만 표시.
- `maxlength="80"`. 81번째 글자는 입력되지 않는다.
- 전송 버튼 없음 (Enter로 전송, v1과 같음).

## 3. 모바일 레이아웃 (720px 미만, 최소 360px)

세로 순서 (위 -> 아래). 기준 360 x 640.

| 순서 | 요소 | 높이 | 규격 |
|---|---|---|---|
| 1 | 게임 캔버스 | `innerHeight - 132` (2의 배수로 내림) | 가로 화면 폭 전체 (여백, 테두리 없음). 360 x 640에서 360 x 508 CSS = 시야 180 x 254 아트 px |
| 2 | 좌/우 터치 버튼 행 `.touch-row` | 64 (위 8 + 버튼 56) | 좌우 18px(계단 테두리 2px 포함 시각 여백 16), 두 칸 그리드 간격 12px. `.bk-btn.bk-btn--touch` (돌 블록). 왼쪽 [◀ 도트 아이콘(`.bk-ico--arrow.bk-ico--left`) 8px "왼쪽"], 오른쪽 ["오른쪽" 8px ▶ 도트 아이콘], 16px 700 `ink` |
| 3 | 채팅 입력 행 `.chat-row` | 68 (위 12 + 44 + 아래 12) | 좌우 18px. 입력(나머지 가로) + 8px + 전송 버튼 "보내기" (가로 72px, 박스 높이 44, `.bk-btn--primary`) |

- 아래 조작 영역 합계 132px. 계단 테두리와 두께(버튼 아래 4px)를 넣어도 줄 사이 시각 간격이 6px 이상 남는다. 캔버스가 나머지 세로를 모두 쓴다 (하단 빈 공간 없음).
- HUD (캔버스 위 겹침, 여백 8px):
  - 왼쪽 위: 접속자 배지 + 8px + LOCAL MODE 칩 (local 모드만).
  - 오른쪽 위: 로그아웃 작은 버튼 (높이 32, 투명 확장으로 터치 44).
  - 조작 힌트는 숨긴다 (`.hint-desktop`).
  - 360px에서 배지(약 110) + 칩(약 84) + 로그아웃(약 76) + 여백 = 약 300px, 한 줄에 들어간다.
- 카메라: style-guide 6.2 (화면 아래 끝 = 아트 y 250, 위쪽 넘침 `k1`). 닉네임 라벨이 캔버스 안에 들어온다.
- 소프트 키보드: `visualViewport.height - 132`(최소 160px)로 캔버스 세로를 다시 계산한다. 캔버스가 줄고 채팅 행은 키보드 바로 위에 남는다.

### 3.1 터치 버튼 동작 (v1과 같음)

- `pointerdown` -> 해당 방향 이동 시작 + `.is-pressed`. `pointerup`, `pointercancel`, `pointerleave` -> 정지 + `.is-pressed` 제거.
- 두 버튼을 동시에 누르면 나중에 누른 쪽이 우선. 한쪽을 떼면 남은 쪽 방향으로 이동을 계속한다 (누르고 있는 상태일 때만).
- CSS: `touch-action: none; user-select: none; -webkit-user-select: none; -webkit-tap-highlight-color: transparent;`.
- 누르는 동안: 2px 내려감 + 베벨 반전 (style-guide 5.2 눌림).

### 3.2 모바일 전송 버튼

- 잔디 블록 primary, 글자 "보내기" 16px 700 `ink`. 누름 2px.
- 빈 입력 또는 쿨다운 중: 비활성 모양(크림), 글자 `w3`.

## 4. 접속자 수 (v1과 같음)

| 항목 | 규칙 |
|---|---|
| 숫자 | 실시간 Presence에 있는 사용자 수 (나 포함) |
| 표시 | 1명 ~ 999명: "접속 중 N명". 1000명 이상: "접속 중 999명+" |
| 갱신 | Presence 동기화 때마다 갱신. 깜빡임 없이 숫자만 바꾼다 |
| 연결 끊김 중 | 마지막 숫자 유지, 글자 뒤 4px에 6 x 6px 정사각형 점 (`.bk-dot-off`, `w3`) |

## 5. 채팅 입력 동작 (v1과 같음)

### 5.1 키보드

| 키 | 입력 포커스가 없을 때 | 입력 포커스가 있을 때 |
|---|---|---|
| Enter | 채팅 입력으로 포커스 이동 | 전송 (빈 값이면 무시, 한글 조합 중이면 무시) |
| Esc | 아무 동작 없음 | 포커스 해제 (게임으로 복귀). 입력 내용은 남긴다 |
| ← 또는 A | 왼쪽 이동 (누르고 있는 동안) | 입력 문자로 처리 (이동 안 함) |
| → 또는 D | 오른쪽 이동 (누르고 있는 동안) | 입력 문자로 처리 (이동 안 함) |

규칙:
- 입력에 포커스가 있으면 이동 키는 게임에 전달되지 않는다.
- 두 방향 키를 동시에 누르면 나중에 누른 방향으로 이동한다. 한쪽을 떼면 남은 키 방향으로 이동을 계속한다.
- 창이 포커스를 잃으면 (`blur`) 이동을 멈추고 눌림 상태를 초기화한다.
- 키 반복 입력(`repeat`)은 무시하고 누름 상태만 본다.

### 5.2 전송 규칙

| 항목 | 규칙 |
|---|---|
| 앞뒤 공백 | 전송 전 제거 (`trim`) |
| 빈 값 | 전송하지 않는다. 오류 표시 없음 |
| 길이 | 최대 80자. 입력 필드가 막는다 (`maxlength="80"`) |
| 전송 간격 | 1초에 1회 (쿨다운 1000ms). 쿨다운 중 전송 시도는 무시하고 아래 힌트를 0.8초 표시 |
| 쿨다운 힌트 | 채팅 입력 행 바로 위 8px, 가운데. `.bk-chip.bk-chip--hint` "1초 뒤에 다시 보낼 수 있습니다." (데스크톱은 캔버스 아래쪽에 겹쳐 보인다) |
| 전송 성공 | 입력 내용 비우기. 포커스 유지 (계속 채팅 가능) |
| 전송 실패 | 입력 내용 유지. 쿨다운 힌트 자리에 `.bk-banner--error`(글자 12px) "메시지를 보내지 못했습니다." 2초 뒤 사라짐. `role="alert"` |
| 내 말풍선 | 내가 보낸 메시지도 내 캐릭터 위 말풍선으로 바로 보인다 (서버 왕복 기다리지 않음) |

설계 메모: 1초 쿨다운은 디자인이 추가한 클라이언트 제한이다 (ARCHITECTURE에 채팅 빈도 제한 없음).

### 5.3 IME (한글 입력)

- Enter를 눌러 조합이 끝나는 중이면 (`isComposing`) 전송하지 않는다.
- 조합 중 글자 수 카운터는 조합 중인 글자까지 센다 (브라우저 값 기준).

## 6. 아바타, 라벨, 말풍선 표시

| 항목 | 규칙 |
|---|---|
| 아바타 | ARCHITECTURE 블록 아트 계약: 프레임과 기준점, 배치 공식, 레이어 합성, 실루엣 외곽선. 기준점을 월드 `(x, 440)` = 아트 `(round(x/2), 220)`에 맞춘다 |
| 애니메이션 | 이동 중 `walk`(manifest 프레임과 시간), 정지 `side_idle` 한 장. 상태가 바뀌면 walk는 첫 프레임부터. 다른 사용자: 마지막 `move` 수신 후 200ms 안에 위치가 바뀌고 있으면 walk, 아니면 idle |
| 방향 | 이동 방향. 오른쪽 = 원본, 왼쪽 = 좌우 반전(ARCHITECTURE). 정지 시 마지막 방향 유지. 다른 사용자는 `move.dir` |
| 게임 안 front/back | 쓰지 않는다 (캐릭터 생성 미리보기 전용) |
| 발 그림자 | style-guide 6.3 (아바타보다 먼저) |
| 그리기 순서 | 다른 사용자 (월드 x 오름차순) → 내 캐릭터 마지막 |
| 닉네임 라벨 | style-guide 7장. 내 캐릭터 = 노란 라벨(`y2`), 다른 사람 = 짙은 남색 라벨(`hb2`). 발 아래 4~28px |
| 말풍선 | style-guide 8장. 꼬리 끝 = 발 위 `52 * P + 4`px(머리 위 기준선 고정). 5초 표시, 마지막 0.5초 페이드, 최대 4줄 |
| 말풍선 겹침 | 겹쳐도 옮기지 않는다. 늦게 받은 말풍선이 위에 그려진다 |
| 파츠 id | manifest에 없는 id는 해당 파츠 기본값(첫 항목)으로 그린다 (ARCHITECTURE) |
| 성능 | 외형 조합마다 합성 + 외곽선 결과(시트 1장)를 캐시하고 좌우 반전본도 캐시 |
| `prefers-reduced-motion` | 게임 안 애니메이션은 유지 (이동 표현에 필요) |

## 7. 상태와 배너

### 7.1 상태 표

| 상태 | 캔버스 | HUD | 배너 (캔버스 위 가운데) |
|---|---|---|---|
| 입장 중 (에셋 로딩 + 채널 접속) | `--letterbox` 색 + 가운데 로딩 점 (`.bk-dots`, 색 `c1`) | 숨김 | 정보 배너 `.bk-banner` "마을에 들어가는 중..." |
| 정상 | 게임 진행 | 표시 | 없음 |
| 연결 끊김 (재연결 중) | 마지막 프레임 유지, 아바타 이동 멈춤 | 표시 (접속자 점 표시) | 오류 배너 `.bk-banner--error` "연결이 끊어졌습니다. 다시 연결하는 중..." (`role="status"`) |
| 재연결 실패 | 마지막 프레임 유지 | 로그아웃만 조작 가능 | 오류 배너 "연결하지 못했습니다." + 오른쪽 8px에 작은 primary 버튼 "다시 연결" (`.bk-btn--primary.bk-btn--sm`) |
| 치명적 오류 | `--letterbox` 색 | 숨김 (로그아웃만 표시) | 오류 배너 "마을에 들어갈 수 없습니다. 다시 시도하세요." + 작은 primary 버튼 "다시 시도" |
| 에셋 일부 실패 | 맵 레이어 실패: 그 레이어만 빼고 그림 (`k1` 바탕). 파츠 실패: 그 레이어만 빼고 그림 | 표시 | 없음 (콘솔 경고 1회) |

재연결 규칙 (v1과 같음):
- 끊김 감지 후 자동 재연결을 최대 3회 시도한다. 간격 1초, 2초, 4초.
- 3회 실패하면 "재연결 실패" 상태.
- 재연결 성공 시 배너를 0.5초 뒤 지운다 (페이드).

### 7.2 배너 규격

- 모양: style-guide 5.7 (정보 = 크림 칩 모양, 오류 = 분홍 바탕 + `r3` 계단 테두리 + 아래 두께).
- `.hud-banner`: 가로 `auto`, 최대 `min(480px, 캔버스 가로 - 32px)`. 글자 14px 700, 줄바꿈 허용.
- 위치: 캔버스 위 가운데, 위에서 52px (데스크톱) / 48px (모바일) (HUD 첫 줄 아래).

## 8. 로그아웃 (v1과 같음)

- 누르면 실시간 채널에서 나가고 세션을 끊은 뒤 로그인 화면 (`login.md`)으로 이동.
- 확인 창 없음 (MVP). 채팅 입력 중이었다면 입력은 버린다.
- 전환은 페이드 200ms. 로그인 화면의 배경 `.bk-world`를 새로 만든다.

## 9. 포커스와 접근성 (v1과 같음)

- 게임 캔버스는 `tabindex="0"`이고 `aria-label="버섯마을 맵. 좌우 방향키로 이동, Enter로 채팅"`.
- 키보드 포커스는 캔버스에 있어야 이동 키가 동작한다. 캔버스를 누르면 캔버스로 포커스가 간다.
- 포커스 표시: 캔버스는 `outline: 2px solid var(--focus); outline-offset: -4px` (안쪽). 다른 요소는 style-guide 4.2.
- 말풍선 내용은 `aria-live`로 읽지 않는다 (채팅 스팸 방지). 채팅 전송 실패만 `role="alert"`.
- 터치 버튼과 전송 버튼 44px 이상.
- 색만으로 상태를 구분하지 않는다. 배너와 접속자 점에는 문구가 있다.

## 10. 360 x 640 체크 항목 (QA)

- [ ] 가로 스크롤이 생기지 않는다.
- [ ] 캔버스 360 x 508 CSS px (시야 180 x 254 아트 px), 아래에 터치 버튼 행(64)과 채팅 행(68)만 있고 하단 빈 공간이 없다.
- [ ] 닉네임 라벨 아래 끝(발 + 28px)이 캔버스 아래 끝(발 + 60px)보다 위에 있다.

- [ ] HUD 첫 줄(접속자 배지, LOCAL MODE 칩, 로그아웃)이 한 줄에 들어가고 겹치지 않는다.
- [ ] 좌/우 터치 버튼 박스 높이 56px, 누르는 동안 2px 내려간다.
- [ ] 채팅 입력과 "보내기"가 한 줄에 있다.
