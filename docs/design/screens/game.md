# 화면 설계: 인게임 (맵 + HUD)

참조: `docs/design/style-guide.md` (월드 규격 4장, 아바타 5장, 닉네임 라벨 6장, 말풍선 7장). 실시간 메시지 형식은 ARCHITECTURE 4번 결정을 따른다.

## 1. 구성

| 영역 | 내용 | 구현 방식 |
|---|---|---|
| 게임 캔버스 | 하늘, 구름, 언덕, 잔디, 흙, 아바타, 닉네임 라벨, 말풍선 | Canvas 2D |
| 상단 바 | 접속자 수, 조작 힌트 (데스크톱), 로그아웃 | DOM |
| 채팅 입력 | 입력 필드, 글자 수, 전송 버튼 (모바일) | DOM |
| 터치 버튼 | 왼쪽 이동, 오른쪽 이동 (모바일) | DOM |
| 상태 배너 | 연결 중, 연결 끊김, 오류 | DOM |

채팅 기록 패널은 없다. 채팅은 말풍선으로만 보이고 저장하지 않는다 (ARCHITECTURE 4번).

## 2. 데스크톱 레이아웃 (720px 이상)

뷰포트 전체를 쓴다. 게임 캔버스는 가운데 정렬, 16:9, 최대 1280 x 720 CSS px. 캔버스 바깥 빈 공간은 `letterbox` (`#1B140E`)로 채운다.

| 요소 | 위치 | 규격 |
|---|---|---|
| 접속자 배지 | 캔버스 왼쪽 위, 여백 16px | 배경 `rgba(255,249,240,0.92)`, 테두리 1.5px `border`, 모서리 `radius-pill`, 패딩 6px 12px, 글자 `fs-sm` 14px 700 `text`. 내용: "접속 중 N명" |
| 조작 힌트 | 캔버스 오른쪽 위, 여백 16px | 배경 `rgba(255,249,240,0.92)`, 모서리 `radius-pill`, 패딩 6px 12px, 글자 `fs-xs` 12px `text-muted`. 내용: "← → 또는 A D 이동 · Enter 채팅 · Esc 입력 해제" |
| 로그아웃 버튼 | 조작 힌트 오른쪽 (또는 힌트 아래) | 높이 32px, 패딩 0 12px, 배경 `panel`, 테두리 1.5px `border-strong`, 모서리 `radius-md`, 글자 `fs-sm` 14px 700 `secondary-text`. 호버 배경 `secondary-soft` |
| 채팅 입력 바 | 캔버스 아래쪽 가운데, 캔버스 하단에서 16px 위 | 가로 `min(560px, 100% - 48px)`, 높이 40px, 배경 `panel`, 테두리 1.5px `border`, 모서리 `radius-md`, 그림자 `shadow-panel` |

### 2.1 채팅 입력 바 구성 (데스크톱)

- 입력 필드: 가로 나머지, 높이 40px, 패딩 0 12px, 글자 `fs-md` 16px. 플레이스홀더: "메시지를 입력하세요" (`text-muted`).
- 글자 수 표시: 입력 필드 오른쪽 안쪽. 형식 "N/80", `fs-xs` 12px `text-muted`. 입력 시작 후에만 표시.
- 포커스 시: 바 테두리 2px `secondary`, 바깥 3px `focus` 링 (투명도 40%).
- `maxlength="80"`. 81번째 글자는 입력되지 않는다.

## 3. 모바일 레이아웃 (720px 미만, 최소 360px)

세로 순서 (위 -> 아래). 기준 폭 360px, 좌우 여백 16px.

| 순서 | 요소 | 높이 | 규격 |
|---|---|---|---|
| 1 | 상단 바 | 48px | 왼쪽 접속자 배지 "접속 중 N명", 오른쪽 로그아웃 버튼 (높이 36px, 가로 auto, 최소 터치 44px) |
| 2 | 게임 캔버스 | 185px | 가로 `100vw - 32px` = 328px, 세로 185px (16:9). 모서리 `radius-lg`, 테두리 2px `#2B2118` |
| 3 | 좌/우 터치 버튼 | 56px | 두 버튼 가로 50% (간격 8px). 모서리 `radius-md`, 배경 `panel`, 테두리 1.5px `border-strong`, 글자 `fs-md` 16px 700 `text`. 왼쪽 "◀ 왼쪽", 오른쪽 "오른쪽 ▶" |
| 4 | 채팅 입력 행 | 44px | 입력 필드 (가로 나머지) + 전송 버튼 "보내기" (가로 72px, 높이 44px) |

- 모든 세로 간격 8px. 전체 높이 약 390px이므로 360 x 640 뷰포트에 들어간다.
- 캔버스 CSS 크기는 `style-guide.md` 4.1 규칙을 따른다. 시야는 480 x 270 논리 단위이며 카메라 세로 기준은 200으로 고정한다.

### 3.1 터치 버튼 동작

- `pointerdown` -> 해당 방향 이동 시작. `pointerup`, `pointercancel`, `pointerleave` -> 정지.
- 두 버튼을 동시에 누르면 나중에 누른 쪽이 우선. 한쪽을 떼면 남은 쪽 방향으로 이동을 계속한다 (누르고 있는 상태일 때만).
- CSS: `touch-action: none; user-select: none; -webkit-user-select: none;` 버튼에 적용.
- 누르는 상태: 배경 `secondary-soft`, 테두리 `secondary`.

### 3.2 모바일 채팅 전송 버튼

- 기본: 배경 `primary`, 글자 `primary-text` 700, 그림자 `shadow-btn`.
- 빈 입력 또는 쿨다운 중: 비활성 (`panel-alt`, `text-disabled`).

## 4. 접속자 수

| 항목 | 규칙 |
|---|---|
| 숫자 | 실시간 Presence에 있는 사용자 수 (나 포함) |
| 표시 | 1명 ~ 999명: "접속 중 N명". 1000명 이상: "접속 중 999명+" |
| 갱신 | Presence 동기화 때마다 갱신. 깜빡임 없이 숫자만 바꾼다 |
| 연결 끊김 중 | 마지막 숫자 유지, 옆에 작은 점 (`•` 8px 원, 색 `text-muted`) 표시 |

## 5. 채팅 입력 동작

### 5.1 키보드

| 키 | 입력 포커스가 없을 때 | 입력 포커스가 있을 때 |
|---|---|---|
| Enter | 채팅 입력으로 포커스 이동 | 전송 (빈 값이면 무시, 한글 조합 중이면 무시) |
| Esc | 아무 동작 없음 | 포커스 해제 (게임으로 복귀). 입력 내용은 남긴다 |
| ← 또는 A | 왼쪽 이동 (누르고 있는 동안) | 입력 문자로 처리 (이동 안 함) |
| → 또는 D | 오른쪽 이동 (누르고 있는 동안) | 입력 문자로 처리 (이동 안 함) |

규칙:
- 입력에 포커스가 있으면 이동 키는 게임에 전달되지 않는다.
- 두 방향 키를 동시에 누르면 나중에 누른 방향으로 이동한다. 한쪽을 떼면 남은 키 방향으로 이동을 계속한다.
- 창이 포커스를 잃으면 (`blur`) 이동을 멈추고 눌림 상태를 초기화한다.
- 키 반복 입력(`repeat`)은 무시하고 누름 상태만 본다.

### 5.2 전송 규칙

| 항목 | 규칙 |
|---|---|
| 앞뒤 공백 | 전송 전 제거 (`trim`) |
| 빈 값 | 전송하지 않는다. 오류 표시 없음 |
| 길이 | 최대 80자. 입력 필드가 막는다 (`maxlength="80"`) |
| 전송 간격 | 1초에 1회 (쿨다운 1000ms). 쿨다운 중 전송 시도는 무시하고 아래 힌트를 0.8초 표시 |
| 쿨다운 힌트 | 입력 바 위쪽 8px, 배경 `panel`, 글자 `fs-xs` 12px `text-muted`, "1초 뒤에 다시 보낼 수 있습니다." |
| 전송 성공 | 입력 내용 비우기. 포커스 유지 (계속 채팅 가능) |
| 전송 실패 | 입력 내용 유지. 배너 없이 입력 바 아래 한 줄 "메시지를 보내지 못했습니다." (`error`, 12px). 2초 뒤 사라짐 |
| 내 말풍선 | 내가 보낸 메시지도 내 캐릭터 위 말풍선으로 바로 보인다 (서버 왕복 기다리지 않음) |

설계 메모: 1초 쿨다운은 디자인이 추가한 값이다 (ARCHITECTURE에 채팅 전송 빈도 제한은 없다). 연타와 스팸을 줄이기 위한 클라이언트 제한이며, 필요하면 메인이 서버 제한과 함께 확정한다.

### 5.3 IME (한글 입력)

- Enter를 눌러 조합이 끝나는 중이면 (`isComposing`) 전송하지 않는다.
- 조합 중 글자 수 카운터는 조합 중인 글자까지 센다 (브라우저 값 기준).

## 6. 아바타와 말풍선 표시

| 항목 | 규칙 |
|---|---|
| 아바타 | `style-guide.md` 5장. 캔버스 64 x 96 기준, 발 위치 y 440 |
| 방향 | 이동 방향으로 좌우 반전. 정지 시 마지막 방향 유지 |
| 흔들림 | 이동 중 상하 2px, 0.4초 주기 |
| 닉네임 라벨 | `style-guide.md` 6장. 내 캐릭터는 주황 배경 (`label-self-bg`) |
| 말풍선 | `style-guide.md` 7장. 5초 표시, 마지막 0.5초 페이드 |
| 말풍선 줄 수 | 최대 4줄. 넘치면 `…`으로 자른다. 전체 글은 표시하지 않는다 (설계 메모 참고) |

설계 메모: 80자 채팅은 말풍선 폭 200px에서 한글 기준 4줄을 넘을 수 있다. 4줄 초과는 말줄임으로 처리한다. 전체 글은 보이지 않아도 되는 것으로 본다 (채팅 기록 없음 정책).

## 7. 상태와 배너

### 7.1 상태 표

| 상태 | 캔버스 | HUD | 배너 (상단, 가운데 정렬) |
|---|---|---|---|
| 입장 중 | `letterbox` 색 화면 + 가운데 스피너 (24px) | 숨김 | "마을에 들어가는 중..." (`text-muted`, 배경 `panel`) |
| 정상 | 게임 진행 | 표시 | 없음 |
| 연결 끊김 (재연결 중) | 마지막 프레임 유지, 아바타 이동 멈춤 | 표시 (접속자 점 표시) | "연결이 끊어졌습니다. 다시 연결하는 중..." (배경 `error-bg`, 글자 `error`, `role="status"`) |
| 재연결 실패 | 마지막 프레임 유지 | 로그아웃만 조작 가능 | "연결하지 못했습니다." + 버튼 "다시 연결" (`primary`) |
| 치명적 오류 | `letterbox` 색 화면 | 숨김 | "마을에 들어갈 수 없습니다. 다시 시도하세요." + 버튼 "다시 시도" (`primary`) |

재연결 규칙:
- 끊김 감지 후 자동 재연결을 최대 3회 시도한다. 간격 1초, 2초, 4초.
- 3회 실패하면 "재연결 실패" 상태.
- 재연결 성공 시 배너를 0.5초 뒤 지운다 (페이드).

### 7.2 배너 규격

- 가로 `min(480px, 100% - 32px)`, 높이 auto, 패딩 8px 16px, 모서리 `radius-md`, 그림자 `shadow-panel`.
- 위치: 상단 바 바로 아래 8px.
- 글자 `fs-sm` 14px, 가운데 정렬.

## 8. 로그아웃

- 누르면 실시간 채널에서 나가고 세션을 끊은 뒤 로그인 화면 (`login.md`)으로 이동.
- 확인 창 없음 (MVP). 채팅 입력 중이었다면 입력은 버린다.
- 전환은 페이드 200ms.

## 9. 포커스와 접근성

- 게임 캔버스는 `tabindex="0"`이고 `aria-label="버섯마을 맵. 좌우 방향키로 이동, Enter로 채팅"`.
- 키보드 포커스는 캔버스에 있어야 이동 키가 동작한다. 캔버스를 누르면 캔버스로 포커스가 간다.
- 포커스 링: 3px `focus`.
- 말풍선 내용은 `aria-live`로 읽지 않는다 (채팅 스팸 방지). 대신 채팅 입력의 전송 실패만 `role="alert"`로 알린다.
- 터치 버튼과 전송 버튼 44px 이상.
- 색만으로 상태를 구분하지 않는다. 배너와 접속자 점에는 문구가 있다.

## 10. 360px 체크 항목 (QA 확인용)

- [ ] 가로 스크롤이 생기지 않는다.
- [ ] 상단 바 접속자 배지와 로그아웃 버튼이 한 줄에 들어간다.
- [ ] 캔버스 세로 185px, 가로 328px, 16:9 유지.
- [ ] 좌/우 터치 버튼이 각각 44px 이상 높이.
- [ ] 채팅 입력과 "보내기"가 한 줄에 있다.
- [ ] 소프트 키보드가 올라와도 채팅 입력이 가려지지 않는다 (입력 포커스 시 캔버스 높이를 줄이지 않고 뷰포트 하단에 입력 행이 남도록 스크롤).
