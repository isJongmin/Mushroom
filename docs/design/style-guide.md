# 버섯마을 스타일 가이드

버전: 3.0 (2026-10-14, 사이클 3 블록 스타일 전면 개정)
정본 범위: 팔레트 42색(HEX), UI 디자인 토큰(CSS 변수), 블록 UI 컴포넌트, 게임 화면 배율과 카메라, 닉네임 라벨, 말풍선, 모바일 배치 원칙.
상위 계약: `docs/ARCHITECTURE.md` "블록 아트 계약" — 아바타 프레임, 기준점, 시트, 레이어, 외곽선, 맵 매니페스트, 표시 배율의 정본이다. 이 문서는 그 값을 다시 정의하지 않고 참조만 한다.
구현 파일: `docs/design/ui-kit.css` — 이 문서의 토큰과 컴포넌트를 그대로 옮긴 CSS. 프런트는 이 파일을 가져다 쓴다. 문서와 CSS가 다르면 이 문서가 정본이고, 디자인이 CSS를 고친다.

폐기(사이클 2 픽셀아트): 32x48 프레임과 기준점 (16,46), 해부도/영역 지도, 파츠 격자, 6프레임 시트, 맵 레이어 7종 표, UI 스킨 PNG(`assets/ui/*.png`, 9-slice, `border-image`), 재료 램프 표(아트 handoff로 이관), `docs/design/ref/` 의 사이클 2 시안 11장(`ref/c3/` 가 현재 시안).
바뀌지 않은 것: 화면 흐름, 모든 문구와 입력 규칙, 월드 2400x540과 지면 y=440, 이동 속도와 범위, 말풍선 규칙(5초, 4줄, 80자), 접근성 규칙.

## 0. 표기와 단위

| 단위 | 뜻 | 관계 |
|---|---|---|
| 아트 px | PNG 한 픽셀 | 월드 2단위 = 아트 1px (ARCHITECTURE) |
| 월드 단위 | 게임 로직 좌표 | 2400 x 540, 지면 y = 440 |
| CSS px | 화면 크기 | 게임: 아트 1px = `P` CSS px (6.1절) |
| UI 픽셀 `U` | 블록 UI 한 칸 | 항상 2 CSS px. 테두리, 베벨, 그림자 두께는 모두 2의 배수 |

- 색은 HEX 대문자 6자리, 이름은 팔레트 토큰(`g2`, `w4` 등). CSS 변수는 `--pal-<토큰>`.
- 프레임 좌표 `(x, y)`는 아바타 프레임 왼쪽 위 기준 아트 px.

## 4. 블록 UI 원칙

### 4.1 계단 테두리 (box-shadow 레시피)

- 블러 0, 퍼짐 0의 바깥 그림자 4개(`0 -2px`, `0 2px`, `-2px 0`, `2px 0`)로 2px 테두리를 그리면 네 모서리 2x2가 비어 1단 계단 모서리가 된다.
- 베벨(3면 톤)은 안쪽 그림자(`inset`)로 그린다.
- 블록 두께(버튼/패널 아래 옆면)는 아래로 옮긴 바깥 그림자 띠로 그린다.
- 바깥 그림자는 "띠"가 아니라 "옮긴 상자 전체"다. `-2px 2px` 같은 대각 오프셋 그림자는 아래쪽 띠까지 덮으므로, 두께 띠(`0 2px` 또는 `0 4px`)를 대각 그림자보다 먼저(위 레이어로) 적는다. `ui-kit.css`의 순서를 바꾸지 않는다.
- 바깥 그림자는 레이아웃에 포함되지 않는다. 컨테이너는 최소 위/좌/우 2px, 아래 6px(패널) 또는 4px(버튼) 여유를 둔다. 조상에 `overflow: hidden`을 두면 잘린다.
- 금지: `border-radius`, 블러 있는 그림자, 반투명 색, 부드러운 그라데이션. 허용: 색이 딱 끊기는 `linear-gradient`(하드 스톱), 도트 아이콘용 다중 box-shadow.

### 4.2 포커스

- 기본: `outline: 2px solid var(--focus); outline-offset: 4px` (계단 테두리 2px 바깥에 2px 간격).
- 입력: 테두리 자체가 파랑(`u3`) 2단 + 안쪽 `u1` 링으로 바뀐다(`outline` 없음).
- 토글 링크, 캔버스: `outline-offset: -4px`(안쪽).

### 4.3 상태 클래스

`:hover`, `:active`와 같은 모양을 `.is-hover`, `.is-pressed`로도 켤 수 있다. 터치 이동 버튼은 `pointerdown`에서 `.is-pressed`를 붙이고 `pointerup/cancel/leave`에서 뗀다. 탭과 프리셋은 `aria-selected` / `aria-checked` / `aria-pressed`로 모양이 바뀐다.

### 5.2 버튼 `.bk-btn`

테마 결정: **primary = 잔디 블록(초록), secondary = 돌 블록(회색)**.

## 6. 게임 화면 규격 (프런트 구현 규칙)

### 6.1 배율 P와 캔버스 크기

정수 배율만(ARCHITECTURE: 기본 2, 1600x900 이상 3).

| 조건 | P | 캔버스 CSS 가로 | 캔버스 CSS 세로 |
|---|---|---|---|
| 모바일 (`innerWidth < 720`) | 2 | `floor(innerWidth / 2) * 2` | `floor((innerHeight - 132) / 2) * 2` (아래 조작 영역 132px) |
| 데스크톱 | 2 | `min(floor(innerWidth / 2) * 2, 1280)` | `min(540, floor((innerHeight - 72) / 2) * 2)` |
| 큰 화면 (`innerWidth >= 1600` 그리고 `innerHeight >= 900`) | 3 | `min(floor(innerWidth / 3) * 3, 1920)` | `min(810, floor((innerHeight - 72) / 3) * 3)` |

- 시야(아트 px) `viewW = cssW / P`, `viewH = cssH / P`. 360x640 폰: 180 x 254.
- `viewH` 최소 80. 크기는 `resize`, `visualViewport.resize`마다 다시 계산.

### 6.2 카메라

```
camX = clamp(round(playerArtX - viewW / 2), 0, max(0, 1200 - viewW))
camY = 250 - viewH      // 화면 아래 끝 = 아트 y 250 (지면 220 아래 흙 30 아트 px)
```

- 지면 아래로 항상 60 CSS px(P=2)가 보여 닉네임 라벨(발 + 28px까지)이 잘리지 않는다.
- 월드 위쪽 바깥(y < 0)은 `k1`로 채운다.

### 6.3 그리기 순서

1. `k1` 채움 → 2. 맵 레이어(매니페스트 순서) → 3. 발 그림자(모든 아바타): 지면선 아트 y 220 한 줄, x `ax-7 ~ ax+6`, `g3` (`ax` = 기준점 아트 x, 아트 샘플 장면과 같음) → 4. 아바타(다른 사용자 월드 x 오름차순, 내 캐릭터 마지막) → 5. 닉네임 라벨 → 6. 말풍선(먼저 받은 것부터, 최신이 위) → 7. DOM HUD.

- 아트 해상도 오프스크린에 1–4를 그리고 메인 캔버스에 정수 배율로 확대, 5–6은 메인 캔버스에 화면 해상도(x dpr)로 그린다.
- 아바타 아트 좌표 = `round(worldX / 2)`. 라벨과 말풍선도 이 반올림 좌표에서 계산한다(떨림 방지).

## 7. 닉네임 라벨 (Canvas, `.bk-name`이 같은 모양의 DOM 판)

| 항목 | 값 (CSS px, U=2 고정, P와 무관) |
|---|---|
| 기준 | 기준점 화면 좌표 `(ax, fy)`. `ax = (artX - camX) * P`, `fy = (220 - camY) * P` (발바닥 선) |
| 박스 | 높이 20. 가로 `w` = 글자 폭 + 12를 2의 배수로 올림, 최소 24 |
| 위치 | 박스 왼쪽 `bx = round2(ax - w/2)`, 위 `by = fy + 6`. 테두리 포함 범위 `fy + 4 ~ fy + 28` |
| 다른 사람 | 바탕 `hb2`, 윗줄 2px `hb1`, 테두리 2px `ink` 계단. 글자 `white` + 그림자 (+1,+1) `ink` |
| 내 캐릭터 | 바탕 `y2`, 윗줄 2px `y1`, 아랫줄 2px `y3`, 테두리 2px `y4` 계단. 글자 `ink` + 그림자 (0,+1) `y1` |
| 글자 | 12px 700, 가운데, 글자 위 = `by + 2` (textBaseline top, 줄 16) |
| 화면 안 보정 | `bx`를 `[4, canvasW - w - 4]`로 제한 |

Canvas 그리기(`fillRect`, 모두 CSS px x dpr):
1. 테두리: `(bx, by-2, w, 2)`, `(bx, by+h, w, 2)`, `(bx-2, by, 2, h)`, `(bx+w, by, 2, h)` — 모서리 2x2는 비운다.
2. 바탕 `(bx, by, w, h)` → 윗줄 `(bx, by, w, 2)` → (내 라벨만) 아랫줄 `(bx, by+h-2, w, 2)`.
3. 글자 그림자 → 글자. `fillText`만(HTML 금지).

## 8. 말풍선 (Canvas, `.bk-bubble`이 같은 모양의 DOM 판)

### 8.1 모양

| 항목 | 값 |
|---|---|
| 박스 | 바탕 `white`, 아랫줄 2px `c2`(블록 아랫면), 테두리 2px `hb2` 계단 |
| 안쪽 여백 | 위 6, 좌우 10, 아래 8 |
| 글자 | 14px 700 / 줄 18, `ink`, 그림자 없음 |
| 크기 | 가로 = 가장 긴 줄 + 20, 최소 40, 최대 200(2의 배수로 올림). 세로 `h` = 줄 수 x 18 + 14 |
| 줄바꿈 | 글자 폭 180 기준, 공백 우선, 공백 없으면 글자 단위. 최대 4줄, 넘으면 4번째 줄 끝 `…` |
| 꼬리 | 계단 3단, 폭 12 / 8 / 4, 박스 아래 끝에서 8px 내려간 곳이 꼬리 끝 |

### 8.2 위치 (기준점 기준)

- 머리 위 기준선: 기준점에서 아트 52px 위(프레임 y 8 = 가장 높은 모자 꼭대기). 머리 모양, 모자와 무관하게 고정해 여러 말풍선 높이가 맞는다.
- 꼬리 끝 `ty = fy - 52 * P - 4`. 박스 아래 끝 = `ty - 8`, 박스 위 `by = ty - 8 - h`.
- 꼬리 가로 중심 `tx = round2(ax)`. 박스 왼쪽 `bx = round2(ax - w/2)`를 `[8, canvasW - w - 8]`로 제한하고, `tx`는 `[bx + 10, bx + w - 10]`로 제한.
- 세로 보정: `by - 2 < 4`이면 `by = 6`으로 내리고 꼬리를 그리지 않는다.

Canvas 그리기 (`b = by + h`):
1. 테두리 4줄(라벨과 같은 방식, `hb2`) → 바탕 `white (bx, by, w, h)` → 아랫줄 `c2 (bx, b-2, w, 2)`.
2. 꼬리: `c2 (tx-4, b, 8, 2)` / `hb2 (tx-6, b+2, 2, 2)`, `c2 (tx-4, b+2, 8, 2)`, `hb2 (tx+4, b+2, 2, 2)` / `hb2 (tx-4, b+4, 2, 2)`, `c2 (tx-2, b+4, 4, 2)`, `hb2 (tx+2, b+4, 2, 2)` / `hb2 (tx-2, b+6, 4, 2)`.
3. 글자: x = `bx + 10`, 첫 줄 y = `by + 6`, 줄 18.

### 8.3 규칙 (사이클 1과 같음)

표시 5초, 마지막 0.5초 `globalAlpha` 1 → 0. 같은 사용자의 새 말풍선은 기존 것을 즉시 교체. 텍스트는 `fillText`만. 채팅 저장 없음.
