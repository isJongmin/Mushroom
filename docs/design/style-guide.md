# 버섯마을 스타일 가이드

버전: 1.0 (2026-10-14)
정본(canonical) 범위: 색상, 폰트, 간격, 게임 월드 규격, 아바타 규격, 닉네임 라벨, 말풍선.
아트팀(SVG)과 프런트팀(Canvas, DOM UI)은 이 문서의 값을 그대로 사용한다. 값을 바꾸려면 디자인 팀이 문서를 먼저 고친다.

표기 규칙
- 모든 길이는 px. 캔버스 좌표(아바타)는 "캔버스 px", 화면 표시 크기는 "화면 px(CSS px)"로 구분한다.
- 색은 HEX 대문자 6자리. 투명도가 필요한 색만 rgba()로 쓴다.

## 2. 타이포그래피

### 2.1 폰트 스택

외부 폰트 로드 금지 (Google Fonts, CDN 폰트 모두 금지). 시스템 폰트만 사용한다.

```
--font-ui: system-ui, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", "Noto Sans CJK KR", "Segoe UI", sans-serif;
```

Canvas 텍스트(라벨, 말풍선)도 같은 스택을 `ctx.font`에 쓴다. 예: `ctx.font = "700 12px " + FONT_UI;`

### 2.2 크기 단계 (px)

| 토큰 | 크기 | 줄간격 | 굵기 | 용도 |
|---|---|---|---|---|
| `fs-xs` | 12px | 16px | 400 / 700 | 도움말, 오류 설명, 닉네임 라벨(700), 카운터 |
| `fs-sm` | 14px | 20px | 400 / 700 | 말풍선 글자, 본문 보조, 필드 라벨(700), 탭 |
| `fs-md` | 16px | 22px | 400 / 700 | 입력 글자, 버튼 글자(700), 파츠 선택 값 |
| `fs-lg` | 20px | 26px | 700 | 화면 제목 |
| `fs-xl` | 28px | 34px | 700 | 로고 "버섯마을" |

규칙: 입력 필드(`input`)의 글자 크기는 모바일 Safari 확대 방지를 위해 항상 16px 이상이다.

## 4. 게임 월드 규격

| 항목 | 값 | 설명 |
|---|---|---|
| 월드 가로 길이 | 2400px | 좌우 끝 사이 전체 너비 |
| 월드 세로 길이 | 540px | 논리 좌표 y 0 (위) ~ 540 (아래) |
| 데스크톱 시야(논리) | 960 x 540 | 뷰포트 폭 720px 이상 |
| 모바일 시야(논리) | 480 x 270 | 뷰포트 폭 720px 미만 (360px 폰 포함) |
| 지면 y (발 위치) | 440px | 아바타 기준점 y가 이 값에 놓인다 |
| 잔디 띠 | y 440 ~ 468 | 잔디 본체 높이 28px |
| 흙 | y 468 ~ 540 | 흙 영역 72px |
| 이동 속도 | 160px/초 (논리) | 등속, 가속 없음 |
| 이동 가능 범위 | 기준점 x 32 ~ 2368 | 월드 끝에서 아바타 반폭만큼 띄움 |
| 이동 방향 | 좌우만 | 점프, 상하 이동 없음 (MVP) |
| 이동 흔들림 | 이동 중 상하 2px, 0.4초 주기 | 정지 시 흔들림 없음 |

### 4.1 카메라

- 가로: `camX = clamp(playerX - viewW / 2, 0, 2400 - viewW)`
- 세로: 데스크톱 `camY = 0` 고정, 모바일 `camY = 200` 고정 (시야 세로 200 ~ 470). 모바일에서 말풍선이 시야 밖으로 나가지 않게 하는 값이다.
- 배율: `scale = min(canvasCssW / viewW, canvasCssH / viewH)`
- 캔버스 CSS 크기: 가로는 뷰포트 기준이며 세로는 16:9를 유지한다. 데스크톱 최대 1280 x 720 CSS px. 모바일은 가로 `100vw - 32px` (360px 폰에서 328 x 185 CSS px).
- 백킹 스토어 해상도: CSS 크기 x `devicePixelRatio`.

### 4.2 그리기 순서 (뒤 -> 앞)

1. 하늘 그라데이션, 구름
2. 먼 언덕
3. 잔디 띠, 흙
4. 아바타 (다른 사용자 먼저, 내 캐릭터 마지막)
5. 닉네임 라벨
6. 말풍선
7. DOM HUD (상단 바, 채팅 입력, 터치 버튼은 캔버스 밖 DOM)

## 5. 아바타 규격 (가장 중요)

### 5.1 캔버스와 기준점

| 항목 | 값 |
|---|---|
| 캔버스 크기 | 64 x 96 캔버스 px (고정) |
| SVG viewBox | `0 0 64 96` |
| 기준점 (anchor) | 발 중앙 `(32, 92)` |
| 배경 | 투명. 파츠 SVG에 배경 사각형을 넣지 않는다 |
| 외곽선 | `#2B2118`, 두께 1.5 캔버스 px, 모서리 `round` |

기준점 해석: 캔버스 y=92가 발바닥이다. 월드 좌표 `(x, 440)`에 서 있는 아바타의 캔버스 좌상단 화면 위치는 `(x - 32 x s, 440 - 92 x s)`이다. `s`는 카메라 배율이다.

좌우 방향: 왼쪽을 보면 캔버스 전체를 기준점 x=32 기준으로 좌우 반전한다 (`scale(-1,1)` around x=32). 얼굴은 정면 기준 좌우 대칭으로 그려서 반전해도 자연스럽게 보이게 한다.

### 5.2 레이어 순서 (아래 -> 위)

1. `skin` (몸 + 얼굴 피부)
2. `bottom` (하의 + 신발)
3. `top` (상의)
4. `eyes` (눈 + 볼터치)
5. `hair` (머리카락)

규칙: 머리카락은 눈보다 위에 그리되, 눈 영역(x 22~42, y 26~38)을 가리지 않는다.

### 5.5 파츠 파일과 기본 조합

- 각 파츠는 독립 SVG다. 크기 `width="64" height="96" viewBox="0 0 64 96"`.
- 파츠 간 겹침은 위 레이어 순서에 따른다. 파츠끼리 빈틈을 두지 않는다. 피부 레이어가 몸통과 팔을 채워서 상의/하의가 빠져도 빈 곳이 보이지 않게 한다.
- 기본 조합 (신규 캐릭터 초기값):

```json
{ "skin": "skin-light", "hair": "hair-round-black", "eyes": "eyes-dot", "top": "top-tee-red", "bottom": "bottom-shorts-navy" }
```

## 6. 닉네임 라벨

| 항목 | 값 |
|---|---|
| 위치 | 기준점(발 중앙) 바로 아래. 라벨 상단 = 발바닥 화면 y + 4px |
| 가로 중심 | 기준점 x (아바타 중심) |
| 글자 | 12px, 굵기 700, 색 `label-text` (`#FFFFFF`) |
| 배경 | `label-bg` (`rgba(43,33,24,0.72)`) |
| 패딩 | 세로 2px, 가로 6px |
| 모서리 | `radius-sm` 4px |
| 내 캐릭터 | 배경 `label-self-bg` (`#FF8A3D`), 글자 `label-self-text` (`#2B1A10`) |
| 최대 길이 | 닉네임 최대 12자 (라벨 폭은 글자 길이에 따름) |
| 크기 기준 | 화면 px. 카메라 배율의 영향을 받지 않는다 |

Canvas에서는 `fillText`를 쓴다. DOM으로 만들면 `textContent`로만 넣는다 (XSS 방지).

## 7. 말풍선

| 항목 | 값 |
|---|---|
| 위치 | 아바타 머리 위. 꼬리 끝은 캔버스 y=4 (머리 최상단) 위 6 화면 px |
| 꼬리 중심 x | 기준점 x (아바타 중심) |
| 꼬리 모양 | 밑변 12px, 높이 8px의 삼각형. 말풍선과 같은 테두리 |
| 말풍선 본체 | 배경 `#FFFFFF`, 테두리 2px `#2B2118`, 모서리 12px |
| 글자 | 14px / 줄간격 18px, 굵기 400, 색 `#2B2118` |
| 패딩 | 세로 8px, 가로 12px |
| 최대 폭 | 200px (화면 px, 패딩 포함) |
| 최소 폭 | 40px |
| 줄바꿈 | 공백 기준. 공백이 없는 긴 글(한글 연속 포함)은 글자 단위로 줄바꿈 |
| 최대 줄 수 | 4줄. 4줄을 넘으면 4번째 줄 끝을 `…`으로 자른다 |
| 표시 시간 | 5초 유지, 마지막 0.5초 동안 투명도 1 -> 0 |
| 중복 | 같은 사용자의 새 말풍선은 기존 것을 즉시 교체한다 |
| 화면 안 보정 | 가로가 시야 밖으로 나가면 좌우 8px 여백 안으로 밀어 넣는다 (꼬리는 아바타 x를 계속 가리킨다) |
| 텍스트 처리 | Canvas `fillText`만 사용한다. HTML로 넣지 않는다 |
| 채팅 저장 | 없음. 말풍선이 사라지면 기록도 사라진다 |

말풍선 자동 높이 계산: 줄 수 x 18 + 16 (패딩) + 꼬리 8. 말풍선 하단 = 꼬리 끝 - 8.
