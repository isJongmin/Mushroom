# 원본 비율 코디 스튜디오

## 변경 방향

체형 프리셋/슬라이더와 시트 변형·필터·Worker를 제거한다. 로컬 프로필 또는 다른 참가자의 이전 `body` 데이터는 외형에서 읽지 않는다. 이동·착지·사다리의 물리 body는 유지한다. 무기는 원래 캐릭터 비율에 맞춘 기존 길고 얇은 그림을 유지한다.

| 항목 | 기존 | 변경 후 |
|---|---:|---:|
| 피부 기본 톤 | 3 | 10 + 직접 색상 지정 |
| 눈·표정 | 4 | 19 |
| 헤어 | 19 | 35 |
| 상의 | 16 | 32 |
| 하의 | 14 | 24 |
| 신발 | 11 | 11 |
| 모자 | 13 | 13 |
| 추천 코디 | 16 | 24 |

추가 64개 선택지는 원본 모양을 유지한 색상 조합이다. 헤어·의상에 새 입체 형상을 추가했다고 표기하지 않는다. 눈은 기본/윙크/나른 표정에 5종 홍채 색상을 추가하며 눈을 감은 웃음 표정은 색상 중복을 만들지 않는다. 기존 선택지와 ID는 유지한다.

## 피부색

10개 기본 톤과 color 입력기·HEX 입력을 제공한다. `#RRGGBB`만 받고 소문자로 정규화한다. 기본 피부 톤 선택은 직접 지정 값을 해제한다. 헤어·의상 변경은 직접 지정 피부색을 보존한다. 잘못된 HEX는 저장 전에 수정하도록 한다. 추천 코디/랜덤 코디는 완성된 조합이므로 직접 색상을 초기화한다.

`skinColor`는 프로필 및 입장 Presence에 별도 nullable HEX로 저장한다. 아바타는 기존 7개 파츠 키를 유지한다. 옛 체형 값은 읽거나 재저장하지 않는다. 다른 기기 자동 프로필 공유는 추가하지 않는다. 같은 방의 새 클라이언트끼리는 커스텀 피부색을 공유하며 구버전은 새 색상 ID를 모르므로 새로고침이 필요하다.

## 색상·성능

원본 PNG의 크기·프레임·알파·윤곽은 그대로 유지한다. 피부 레이어에만 음영을 유지한 톤 변경을 적용하며 얼굴·의상·모자에는 커스텀 피부색을 덮지 않는다. 눈 색상은 갈색 홍채 픽셀에 한정해 흰 반사광과 입/볼은 보존한다. 의상은 원래 소재 색상에 가까운 픽셀을 바꿔 다른 색상의 안감/패치/가방 등을 최대한 보존한다.

새 색상 ID는 원본 ID에 매핑되어 이미 있는 PNG만 요청한다. 음영 레이어는 재사용한다. 필요한 색상만 지연 합성하며, 색상 시트 캐시는 24개, 직접 지정 피부색은 렌더러별 8개로 제한한다. 프레임 렌더링 중 색상을 다시 계산하지 않는다.

## 코디 화면

체형 탭을 없애고 코디 화면을 바로 연다. 색상/스타일 검색, 결과 수, 빈 결과 안내, 아이템 이름을 추가한다. 검색 결과에서 현재 선택이 없더라도 첫 항목이 키보드로 접근 가능하다. 피부색 입력은 피부 탭에서만 표시한다. 수정 취소·초기화·기존 캐릭터 프로필은 유지한다.
