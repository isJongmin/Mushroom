# 가방 UX·장비 일괄 판매·펫 판매·카드 공개

## 동선

- 가방은 장비/펫 두 탭으로 축소한다. 마을 안내와 지역 뽑기 탭은 제거한다.
- 장비/펫 카드를 누르면 하단 상세 영역에 해당 대상의 동작만 표시한다. 카드마다 착용/합성/판매 버튼을 모두 나열하지 않는다.
- 장비는 선택 판매 모드에서 체크박스, 전체 선택, 다른 직업만 선택, 선택 해제를 제공한다. 착용 장비는 선택할 수 없다. 선택 수/총액을 보여주고 별도 확정 후 판매한다.
- 합성은 같은 종류/등급의 두 번째 재료를 찾아 결과 등급을 미리 보여준다. 기본적으로 미착용 재료를 우선하며, 착용 재료가 쓰이면 결과 장비로 교체된다고 확인 화면에 안내한다.
- 탭 이동은 키보드 좌우/Home/End로도 가능하다. 항목마다 접근성 이름과 선택 상태를 제공한다. 긴 목록은 내부 스크롤, 주요 동작은 목록 아래에 유지한다.

## 원자적 판매

`sell-many`는 1~200개의 서로 다른 ID를 받는다. 요청한 장비가 전부 존재하고 모두 미착용인지 검사한 뒤 한 번에 제거하고 총 골드를 지급한다. 누락/중복/착용 ID가 하나라도 있으면 전체 요청을 거절한다. 기존 IndexedDB 트랜잭션과 함께 사용하므로 다른 탭에서 겹치는 장비를 판매해도 중복 골드를 지급하지 않는다.

펫은 종류별 한 마리 보유 모델을 유지한다. `pet-sell`로 보유 펫을 제거하고 일반/고급/희귀/영웅/전설 순으로 20/60/180/600/2,000 G를 지급한다. 동행 중이면 먼저 해제해야 한다. 판매 확정 전에 펫 소멸, 강화 정수 미반환을 명시한다. 재획득하면 강화 0으로 시작한다. 뽑기 가격·확률·천장 및 중복 정수 규칙은 유지한다.

## NPC 전용 뽑기

NPC 상점은 가방과 분리된 화면이다. 1/5/10회 버튼과 보장 남은 횟수를 우선 표시하며, 등장 펫과 확률은 접어서 보되 구매 전에 열어 확인할 수 있다.

뽑기 트랜잭션에서 골드·결과·천장·중복 정수를 먼저 확정하고 저장한다. 그 결과 배열을 별도 표현 상태기계에 전달한다. 카드 공개는 게임 경제 명령을 실행하지 않는다.

`sealed → charging → revealed → sealed … → complete → summary`

- 미공개 카드에는 결과 이름/등급을 표시하지 않는다.
- 열기/다음 카드 클릭 후 850ms의 빛과 흔들림, 카드 뒤집기로 한 마리씩 공개한다.
- 영웅/전설은 등급색 광원, 회전 빛줄기와 반짝임을 추가한다.
- 모두 공개는 공개 타이머를 취소하고 전체 요약으로 이동한다. 닫기/화면 정리는 타이머와 이벤트를 해제한다.
- 중간에 닫거나 새로고침해도 이미 저장된 펫/정수가 유지된다. 다시 결제하거나 재추첨하지 않는다. 공개 진행 위치/뽑기 결과 목록 자체는 영구 이력이 아니다.
- 모션 줄이기 설정에서는 애니메이션을 끄고 공개 대기를 80ms로 줄인다. 공개 완료 후 다음 카드 버튼으로 키보드 포커스를 돌린다.

## 확인

- `node tests/inventory-ux.test.mjs`: 다중 판매의 전체 검증/롤백, 착용 보호, 중복 ID 거부, 펫 등급별 가격/강화 미환급/동행 보호/중복 판매 거부, 겹치는 동시 판매, 한 장씩 공개/중복 진행 방지/모두 공개 상태기계.
- `node tests/progression.test.mjs`: 기존 장비·펫·지역 성장 회귀.
- 브라우저의 별도 QA 데이터로 타 직업 장비 3개 950G 일괄 판매, 강화 펫 180G 판매, 전설 천장 카드 첫 공개, 다음 카드/모두 공개, 공개 중 닫기 후 추가 결제 없이 결과 유지 확인.
- 검증 데이터/별도 QA 페이지는 배포하지 않는다. 서버 저장/검증 범위는 기존 브라우저 저장 구현과 동일하다.

390px 모바일 iframe에서도 장비 목록/합성 확인과 합성 성공, 5회 뽑기 카드 공개를 확인했다.
