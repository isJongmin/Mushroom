# 장비 외형·펫 동작·키보드·모바일 전투 UI

- 일반/고급/희귀/영웅/전설 장비는 색과 함께 단조 장식, 결정 날개, 다단 날개와 보석, 왕관형 고리를 차례로 추가한다. 가방/드롭/캐릭터 착용에 같은 도형을 사용한다.
- 캐릭터 손 위치에 직업 무기를 표시하고 검사 방패를 보조 손에 표시한다. 공격 시 무기를 기울이고 희귀 이상 발밑 빛, 영웅 이상 무기 입자를 추가한다. 밧줄/엎드리기에는 무기를 숨긴다.
- 장비 교체/합성으로 장착 ID가 바뀌면 900ms 등급색 링/입자가 나온다. 가방을 닫은 뒤 한 번 재생한다. 로그인/단순 창 열기에는 재생하지 않는다.
- 15종 펫마다 고유 주기와 이동 유형을 적용한다. 버섯/슬라임/토끼는 점프와 스쿼시, 박쥐/드래곤/정령은 비행/날갯짓, 수정게는 좌우 이동, 골렘은 작은 무거운 걸음, 사슴은 달리기 바운스, 다람쥐는 빠른 흔들림을 사용한다. 실제 이동 방향을 보고 뒤집는다.
- 내 펫은 수집 시 700ms 점프/금색 반짝임, 피격 시 700ms 움츠림/느낌표, 공격 시 450ms 움직임으로 반응한다. 전투 수치/수집 확률은 바꾸지 않는다. 원격 펫도 이동/공격 반응을 그린다.
- 모션 줄이기 설정은 펫 동작과 무기 입자를 정지하고 착용 연출을 단순 링으로 바꾼다.

## 입력

기본공격 J/Ctrl/X, 스킬 K/L/세미콜론. 기존 숫자 1/2/3도 호환한다. 이동 방향키/WASD, 점프 Space 등 기존 이동 규칙은 유지한다. 물리 code를 사용하므로 키보드 입력 언어와 무관하게 같은 위치에서 작동한다. 채팅/편집 필드/모달에서는 스킬을 실행하지 않는다. 버튼의 키 표시와 안내도 갱신한다.

## 모바일

720px 미만에서 공격/세 스킬을 캔버스 아래 전용 도크에 배치하고, 다음 줄에 좌우 이동/엎드리기/점프를 배치한다. PC에서는 기존 캔버스 오버레이 배치다. 모바일 채팅 입력은 버튼으로 열고 닫는다. Enter/ESC도 입력창 열기/닫기를 지원한다. 미니맵은 접힌 상태로 시작하고 크기를 줄인다. 직업/모드/인원 칩과 긴 조작 안내를 숨기고 방 이름, 채팅, 방 삭제(방장), 나가기, 현재 마을/골드/가방만 우선 표시한다. 전투 도크의 잠금/쿨타임 표시는 유지한다. 조작 영역과 펼친 채팅 높이를 제외해 시야 높이를 계산한다.

## 검증

appearance-motion 테스트는 15종의 실제 변환값 차이, 수집/피격/공격 반응, 모션 줄이기, 5등급 도형 차이, 방패/무기 그리기, 밧줄 숨김, K/L/세미콜론 및 숫자 호환을 검사한다. 기존 가방/장비 성장/스킬/밧줄·망토 회귀도 확인한다. 브라우저 390×820 iframe에서 실제 방 진입, 하단 도크, 접힌 지도, 채팅 열기와 K 입력 후 스킬 쿨타임 표시를 확인했다. 실제 휴대폰 터치/가상 키보드 및 Supabase 다중 사용자 세션은 실측하지 않았다.

## 후속 설계 의견 — 미구현

선택한 직업 대신 착용한 주무기가 직업/스킬을 결정하는 안을 추천한다. 검/활/스태프/아대에 검사/궁수/마법사/도적을 연결하고 방패는 보조 장비로 둔다. 해금은 무기 종류별 최고 등급으로 유지하고 교체 시 슬롯별 쿨타임을 이어받아 궁극기 교체 연사를 막는다. 이 패치는 직업 선택/장비 착용 제한을 전환하지 않는다.
