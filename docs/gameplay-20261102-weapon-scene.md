# 무기로 바뀌는 스킬 · 양손 조작 · 전 지역 펫 · 장면 순서

## 장비와 스킬

프로필 꾸미기의 직업 선택 UI를 제거했다. 검/활/스태프/아대 착용 시 검사/궁수/마법사/도적의 기본공격과 세 스킬, 버튼 아이콘/이름/툴팁이 함께 바뀐다. 방패는 모든 주무기의 보조 장비이며 스킬을 변경하지 않는다.

저장 형식 version 1에 `activeWeapon` ID를 추가했다. 이전 저장에는 활성 ID가 없으므로 기존 프로필 직업의 장착 ID를 먼저 선택하고, 없으면 보유 주무기를 선택한다. 기존 장비/골드/펫/강화/천장/최고 획득 등급은 유지한다. 예전 `equipped` 매핑은 이관 호환용으로 남기며 실제 착용/판매 보호는 활성 주무기와 방패에 적용한다. 다른 무기도 자유롭게 착용/판매/합성할 수 있다.

해금은 무기 종류별 최고 획득 등급으로 유지한다. 마을 진입은 어떤 무기든 달성한 최고 등급을 기준으로 하므로 낮은 등급의 새 무기를 시험해도 열린 마을이 다시 잠기지 않는다. 무기 교체는 스킬 슬롯별 남은 쿨타임과 기본공격 간격을 초기화하지 않는다. 이미 발사한 공격은 당시 무기/공격 수치로 마무리한다. 수신 공격의 무기 종류와 직업이 다르면 거절한다. 서버 권위 경제/전투는 기존과 같이 미구현이다.

## 양손 입력

모바일은 왼쪽 엄지 영역에 좌/우/아래, 오른쪽 엄지 영역에 스킬 3개와 점프/큰 공격 버튼을 배치한다. 한 손의 포인터 해제가 다른 손 입력을 지우지 않는 기존 출처별 입력 모델을 유지한다. 데스크톱에서는 WASD 또는 방향키 이동, J/Ctrl/X 공격, K/L/세미콜론 스킬을 사용하며 숫자키도 호환한다. 모바일/PC 경계를 오갈 때 실제 버튼을 재배치하고 기존 리스너를 재사용한다.

## 펫과 깊이

동행 펫은 획득 지역과 무관한 전역 보유/장착 데이터다. 동행 위치는 맵 ID가 바뀌면 새 캐릭터 좌표에서 즉시 다시 잡으며, 잘못된/멀리 떨어진 위치를 이어서 보간하지 않는다. NPC/몬스터/플레이어/펫을 공통 액터 큐로 그린다. 발판/바닥 높이를 우선하고, 같은 높이에서는 NPC → 몬스터 → 플레이어 → 펫 순서다. 고정 배경/발판과 월드 사물은 액터 뒤, 전투 이펙트/이름/HP는 액터 앞이다. 각 액터는 Canvas 상태/변환을 저장·초기화·복원하여 NPC 변환이 펫에 누적되지 않는다.

## 손에 든 무기

`avatar-hand-anchors.js`는 실제 아바타 원본 `assets/_src/art2d/rig.py` 및 `body.hand_pos`에서 13개 프레임의 양손 좌표를 추출한 데이터다. 기존 고정 (23,-32) 위치 대신 현재 프레임의 가까운 손에 손잡이 기준점을 맞춘다. 검/스태프 내부 회전과 활/아대 손잡이 위치도 보정한다. 무기를 그린 뒤 동일 아바타 프레임의 손 주변 픽셀만 다시 그려 손가락이 손잡이 앞에 놓이게 한다. 밧줄/엎드리기/유령에는 무기와 손 보정을 그리지 않는다.

## 확인

- weapon-switch-scene: 이전 데이터 이관/보존, 4종 무기 전환, 슬롯 공유 쿨타임, 무기/직업 위조 조합 거절, 보조 방패, 전역 마을 해금, 버섯 펫의 광산/이끼 이동, 액터 정렬, 13개 손 좌표, 좌우 엄지 입력 독립성.
- appearance-layers: 13프레임 양방향 손 패치 Canvas 균형 및 기존 밧줄/망토/NPC 회귀.
- 기존 progression, inventory-ux, map-protocol, profile-jobs(이전 프로필 데이터 호환), appearance-motion, skill-patterns 회귀.
- 실제 브라우저의 390px iframe에서 검 → 활 → 스태프 교체에 따른 스킬 이름/아이콘, 궁극기 사용 후 교체, 왼손/오른손 영역, 광산에서도 보이는 버섯마을 전설 펫과 새 맵 동행 좌표를 확인했다. 테스트 전용 캐릭터/아이템 및 포탈 위치 도우미를 사용했으며 배포 소스에는 포함하지 않는다.
- 실제 휴대폰 다중 터치/가상 키보드와 Supabase 실시간 다중 사용자 세션은 실측하지 않았다.

추가 브라우저 확인: 광산 → 이끼에서도 `village:4` 펫과 새 맵 동행 좌표가 유지되고 화면에 표시된다. 꾸미기 화면의 `job-picker` 요소 수가 0임을 확인했다.
