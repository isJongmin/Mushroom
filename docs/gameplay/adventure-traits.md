# 모험 특성 · 수련 퀘스트 (2026-11-03)

## 조작과 화면

메뉴 → 모험 특성은 `능력 배분 / 수련 퀘스트` 두 탭으로 나뉜다.
배분 화면에는 공격력·최대 체력·스킬 재사용의 효과/현재값/−·+만 먼저 보이고, 스킬별 상세는 펼쳐 볼 수 있다.
퀘스트 화면은 지역을 선택해서 수락 전·진행 중·완료 보고·보상 수령 상태를 확인한다.
탭을 바꿔도 미적용 배분은 유지한다. 적용을 눌러 저장에 성공한 뒤 실제 능력치가 바뀐다.
평소 좌측 상단에는 가방 버튼만 표시한다. 골드·공격력·사냥 의뢰 진행도는 HUD에 상시 표시하지 않는다.

## 수련 스승

| 지역 | NPC | 칭호 |
|---|---|---|
| 버섯 | 검성 하겐 | 새벽 검술의 계승자 |
| 광산 | 철권 바르칸 | 수정 갱도의 수호무인 |
| 이끼 | 대현자 아르웬 | 세계수의 오랜 스승 |
| 서리 | 빙설군주 카이론 | 영원의 서리를 다스리는 자 |

각 지역 스폰에서 오른쪽 약 360 월드 픽셀 지면에 서며, 미니맵에 노란 표식을 표시한다.
스승의 머리 위 `!`는 새 수련, `?`는 보상 수령 가능, `…`는 진행 중을 뜻한다.
NPC 초상화·이름·대사가 있는 대화창에서 수련을 선택하고 수락한다. 조건을 달성한 뒤 같은 지역 스승에게 완료 보고하여 포인트를 받는다.
이미 쌓은 사냥/탐험 기록도 목표에 인정하므로 수락 전에 달성했다면 수락 후 즉시 보고할 수 있다.
기존 안내 NPC의 지역 방어/보스 도전 메뉴와 수련 스승은 별개다.

참고한 기본 흐름: [메이플스토리 공식 퀘스트 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/442)의 NPC 수락 → 수행 → NPC 보상 및 미니맵 !/? 표시. 캐릭터·이름·대사·그래픽은 이 프로젝트용으로 구성했다.

## 포인트와 능력치

최대 획득 15점, 각 가지 최대 10점이다. 전투 숙련/강인한 신체는 각각 점당 +5%, 기술 연마는 공격 스킬/궁극기 쿨타임을 점당 −2% 줄인다.
공격/체력은 세 펫의 보너스를 합산한 뒤 특성을 한 번 곱한다. 기본 공격 간격 360ms와 이동/공격 애니메이션은 바꾸지 않는다.

- 버섯: 첫 20회 사냥 의뢰 / 몬스터 5종 각 10회 / 보스 첫 처치 = 3점.
- 광산·이끼·서리: 탐험 3곳 / 몬스터 5종 각 20회 / 방어 첫 성공 / 보스 첫 처치 = 각각 4점.
- 유효 피해를 준 처치 참여 경로로 기록한다. 이벤트 몬스터는 일반 사냥/종류별 처치에 포함하지 않는다.
- 보스 목표는 해당 보스에게 유효 피해를 준 성공 참여자에게 기록한다.
- 신규 포인트는 목표 달성만으로 자동 지급하지 않는다. 수락과 완료 보고가 필요하다.
- 배분·초기화는 연결/생존/수련 스승 근처/최근 5초간 공격·피격 없음 조건을 저장 시점에도 검사한다.
- 재분배는 현재 HP를 회복시키지 않는다. 새 최대 HP보다 높을 때만 자른다. 이미 시작한 쿨타임도 시전 당시 만료 시각을 유지한다.

## 강화 연출

수련 보상과 특성 강화 적용 시 캐릭터를 감싸는 빛이 나타난다. 적용한 특성은 지속적으로 은은한 오라를 표시한다.
공격은 금빛, 체력은 녹색, 기술은 청색이며 여러 특성은 가장 많이 배분한 가지의 색을 쓴다.
원격 캐릭터도 정리된 loadout에서 같은 오라를 그린다. 동작 줄이기 설정에서는 회전 입자를 생략하고 정적인 빛을 사용한다.

## 저장·이관

`traits.questVersion=1`, 고정 목표별 `quests[key]=active/claimed`를 추가한다.
기존 포인트는 증거로 확인되는 완료 조건을 claimed로 한 번 이관하여 배분을 보존한다. 장비/펫/골드/정수/최고 등급/기존 보상도 유지한다.
기존 버섯 보스 보상 소급은 초기 저장 전환에서만 수행한다. 이후 새 보스 성공 뒤 재접속해도 NPC 보고를 우회하지 않는다.
종류별 고유 영수증, 탐험 지점 ID, 지역별 성공 기록은 계속 보존한다. 포인트는 알려진 목표의 검증된 claimed 기록에서 계산한다.
수락·보고·배분을 IndexedDB readwrite 트랜잭션으로 처리하고, 완료 보고 중복 전송/동시 탭에서도 같은 포인트를 두 번 주지 않는다.
NPC 위치와 지역은 트랜잭션 실행 시점에 검사한다. 배분은 각 0~10 정수/합계 ≤ 획득량과 revision을 검사한다.
브라우저 저장 + 호스트 시뮬레이션이며 서버 권위 위변조 방지 경제는 아니다.

## 검증

- 전체 JavaScript 테스트 28개 통과. 신규 퀘스트 수락/완료 보고/중복/구형 포인트 이관/재접속 우회 방지/잘못된 키/동시 보고/NPC 위치 가드/오라 Canvas 검증을 포함한다.
- 실제 로컬 게임에서 전용 합성 진행도 캐릭터로 NPC 대화 → 수락 → 완료 보고 → 포인트 수령 → 특성 적용을 확인했다.
- 능력 배분/수련 퀘스트 탭 전환 시 미적용 배분 유지, 390px 모바일 배분 화면과 NPC 초상화/대사/수락 버튼 배치를 확인했다.
- 수련에 쓴 사냥 기록은 합성 데이터다. 신규 계정의 전 지역 15개 수련을 실제 플레이로 끝내는 데 걸리는 시간은 미측정이다.
- `scripts/adventure-traits-balance.mjs`는 단일 전설 펫 +5 기준의 이론 화력 모델이며 실제 사냥 실측/3마리 최종 밸런스 평가가 아니다.
