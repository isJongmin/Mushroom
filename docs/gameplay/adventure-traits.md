# 모험 특성 구현 (2026-11-03)

## 플레이 방법

게임 메뉴 → 모험 특성, 또는 지역 안내 NPC → 모험 특성 · 무료 재분배.
각 특성은 최대 10점, 전체 획득 가능 포인트는 15점이다.
전투 숙련과 강인한 신체는 각각 점당 5%, 기술 연마는 공격 스킬/궁극기 쿨타임을 점당 2% 줄인다.
공격·체력은 펫 적용 후 독립 곱연산하며 각 가지 안에서는 합산한다.
기본 공격 간격(360ms), 이동, 공격 애니메이션은 바꾸지 않는다.

배분은 미리보기 후 적용한다. 저장이 성공한 뒤 실제 능력치가 반영된다.
지역 안내 NPC에서 가로 230/세로 100 이내, 연결됨, 생존, 마지막 공격·피격에서 5초 경과가 필요하다.
이 조건은 저장 트랜잭션이 실행되는 시점에도 재검사한다.
초기화도 미리보기와 적용을 거치며 현재 HP를 회복시키지 않는다. 새 최대 HP보다 높을 때만 현재 HP를 자른다.
이미 시작한 스킬 쿨타임은 재분배해도 그 시전 당시 만료 시각을 유지한다.

## 최초 획득 조건

- 버섯: 첫 사냥 의뢰 20회 / 몬스터 5종 각 10회 / 보스 첫 처치 = 3점.
- 광산·이끼·서리: 탐험 3곳 / 몬스터 5종 각 20회 / 방어 첫 성공 / 보스 첫 처치 = 각각 4점.
- 탐험은 입구(지면 x650), 위층(광산/서리 mine-lift 또는 이끼 ancient-bough), 깊은 곳(맵 끝에서 550 안쪽 지면)이다. 맵에 깃발과 발견 상태를 표시한다.
- 유효 피해를 준 기존 처치 참여 보상 경로에 몬스터 종류를 추가했다. 이벤트 몬스터는 일반 사냥·종류별 처치에 포함하지 않는다.
- 지역 이벤트 성공과 유효 참여를 확인하며, 보스 포인트는 해당 보스에게 유효 피해를 준 참여자에게 지급한다.
- 반복 의뢰·동일 성공 이벤트 재전송으로 추가 포인트를 지급하지 않는다.

## 저장과 마이그레이션

기존 equipment-v1의 버전/장비/펫/골드/최고 등급/기존 보상을 보존하고 `traits` 증거 기록을 추가한다.
포인트는 임의의 earned/completed 숫자가 아니라 15개 고정 조건을 증거에서 계산한다.
각 몬스터 종류는 목표치까지 고유 처치 영수증을 보관한다. 일반 영수증 캐시가 만료되어도 같은 영수증으로 종류별 처치를 다시 늘릴 수 없다.
탐험은 고정 지점 ID의 집합, 이벤트는 지역별 최초 성공 여부로 저장한다.
기존 총 처치로 확인 가능한 버섯 첫 의뢰와 버섯 보스 보상 기록만 소급한다. 종류별 처치·탐험·다른 지역 보스는 추정하지 않는다.
배분은 정수 0~10/합계 ≤ 획득량을 검사하며, revision이 바뀐 동시 저장은 거부한다.
IndexedDB readwrite 트랜잭션 안에서 검사·증거 갱신·배분을 처리한다. 원격 loadout에도 배분을 정리해서 전달한다.
클라이언트 저장 + 호스트 시뮬레이션 구조이며 서버 권위의 위변조 방지 경제는 아니다.

## 검증 결과

- `node tests/adventure-traits.test.mjs`: 15조건/중복/마이그레이션/잘못된 배분/전투 계산/네트워크/쿨타임/동시 탭/저장 실패 검증.
- 전체 JavaScript 테스트 25개 통과.
- 일반 로컬 게임에서 신규 캐릭터 생성 → 방 생성 → 메뉴 → 특성 화면 진입 및 초기 0점 상태 확인.
- 합성 진행 데이터를 주입한 별도 브라우저 QA에서 실제 IndexedDB 동시 배분 두 건 중 1건 성공/1건 거부 확인.
- 동일 QA에서 390px 모바일/데스크톱 화면, 미리보기 → 적용 → 닫기, 현재 HP 300 유지 확인.
- 합성 데이터 QA는 실제 사냥으로 15점을 획득한 플레이 테스트가 아니다. 네 지역 전 구간 실제 플레이 획득 시간과 원격 두 브라우저의 전체 전투는 미측정.
- 일반 몬스터/펫/지역 해금 수치는 변경하지 않았다.

## 화력 모델

`node scripts/adventure-traits-balance.mjs`로 재현한다.
전설 무기와 서리 전설 펫 +5 기준, 단일 대상에 모든 타격이 명중하고 스킬을 쿨타임마다 쓰는 이론 모델이다.
네 직업 모두 이 모델에서는 전투10·기술5의 화력이 가장 높다. 생존/범위 공격/사거리/회피/획득 속도는 이 비교로 평가하지 않는다.

|---|---:|---:|---:|---|---:|
| 검사 | 2315.2 | 3689.8 | 3300.0 | 전투 10 · 기술 5 | +59.4% |
| 궁수 | 1619.4 | 2532.7 | 2217.5 | 전투 10 · 기술 5 | +56.4% |
| 마법사 | 2317.8 | 3670.9 | 3260.9 | 전투 10 · 기술 5 | +58.4% |
| 도적 | 1348.4 | 2128.4 | 1881.9 | 전투 10 · 기술 5 | +57.8% |

전설 무기 + 서리 전설 펫 +5, 모든 타격 명중, 스킬을 쿨타임마다 사용, 스킬 모션만큼 기본 공격 시간을 차감한 이론 모델. 이동·회피·투사체 충돌·범위 피해·플레이어 숙련도·실제 처치 시간은 미포함. 생존 가치나 체력 투자 효율을 평가하지 않으며 실측 결과가 아님.
