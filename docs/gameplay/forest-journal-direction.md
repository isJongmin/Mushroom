# 숲속 모험책: 경험과 화면 구성

## 방향

기능 개수를 늘리는 대신 세계를 주인공으로 두고, 상태·목표·전투 조작을 화면 가장자리에서 읽도록 정리한다. 기존 지역·아이템·펫·보상·성장 데이터를 유지한다. 이 변경은 새 스토리 던전이나 완성된 서사 콘텐츠를 추가한 것이 아니다.

- HUD: 숲색 반투명 상태창, 얇은 HP/EXP 바, 원형 액션. 미니맵은 첫 입장에 접는다.
- 현재 여정: 지역별 챕터 제목과 짧은 분위기 문장. 첫 수련 수락을 먼저 안내하고 이후 기존 목표로 이어간다.
- 길잡이: 목표 버튼으로 추적을 켜고 끈다. NPC에게 충분히 가까우면 기존 대화를 연다. 사냥 경로는 공중 발판 대신 지상의 스폰 구역으로 안내한다. 순간 이동이나 자동 전투를 하지 않는다.
- 공간: 가까운 NPC만 대화 표시를 그린다. NPC 이름·외형과 기존 상호작용 조건은 유지한다.
- 획득: 골드를 짧은 시간 안에 모아 표시하며 최대 3개 알림만 유지한다. 일반 획득의 채팅 스팸을 줄이고 희귀 이상 장비에는 빛기둥과 기록을 남긴다.
- 음향: 다운로드 없는 작은 합성 효과음. 기본 꺼짐, 사용자 입력 후에만 활성화. 저장된 켜짐 상태도 다음 입장에서 자동 재생하지 않고 입력을 기다린다. 빠른 중복 재생과 동시 음성을 제한하고 화면 종료 시 AudioContext를 닫는다.
- 접근성: 44px 이상 목표 버튼, 키보드 포커스, 명시적인 추적 상태, 모션 줄이기에서 정적인 길잡이·알림.

## 검증

journey-polish 테스트: 첫 수련·탐험 목표, 지상 사냥 경로, 원본 맵 비변경, 방향·도착 판정, 정적 길잡이, Canvas 상태 복원, 합산/제한/만료 알림, 오디오 지연 생성·옵트인·중복 제한·종료.

## 남은 제작 과제

보스와 지역마다 기억에 남는 전용 사건, 플레이로 전달하는 이야기, 직접 제작한 배경음악과 통일된 추가 아트, 실제 휴대폰에서의 전투·동선 반복 테스트가 필요하다. UI 개편만으로 작품의 완성도를 단정하지 않는다. 서버 검증·계정 저장 과제도 별도로 유지한다.
