# MMORPG 기반 보완

## 판단

| 점검 영역 | 확인한 상태 | 이번 결정 |
| --- | --- | --- |
| 지속 성장 | 장비·펫·유한한 특성에 집중 | 사냥 기록 기반 레벨·경험치 추가 |
| 다음 행동 안내 | 반복 사냥 의뢰가 존재하지만 남은 수량 안내 부족 | 미니맵 아래 다음 목표 1개 표시 |
| 협동 가시성 | 같은 지역 플레이어 및 개인별 참여 보상 존재 | 메뉴에 지역 동료 체력·부활 대기 표시 |
| 초기 로딩 | 직전 패치에서 NPC 전체 선로딩 제거 | 지연 로딩 유지, 팝업 추가 없음 |
| 저장·보상 | IndexedDB 트랜잭션, 드롭 영수증 중복 방지 | 레벨을 별도 잔액으로 저장하지 않고 기존 사냥 증거에서 계산 |
| 서버 신뢰 | 전투 호스트는 클라이언트, 장비·성장은 브라우저 저장 | 거래·공개 랭킹 보류. 서버 권위 전투·경제와 계정별 저장을 후속 우선순위로 둠 |

## 레벨

- Lv.1~30. 현재 레벨 L에서 다음 레벨까지 `80 + 40*(L-1) + 15*(L-1)^2` EXP.
- 일반 지역 사냥 기록 한 건: 버섯 10 / 광산 30 / 이끼 70 / 서리 150 EXP.
- 기존 저장의 `kills`를 그대로 사용하므로 이전 사냥 기록도 반영된다.
- 드롭 줍기와 별개로 사냥 보상 트랜잭션 확정 시 반영된다. 같은 영수증 재처리는 사냥 수·EXP를 늘리지 않는다.
- 방어 이벤트 결과 보상은 일반 사냥 수로 다시 세지 않는다. 보스 보상과 이벤트 보상 구조는 유지한다.
- 레벨당 공격 배율 +1%, 기본 체력 +3. Lv.30에서 공격 배율 +29%, 기본 체력 +87.
- 특성/펫 배율에 레벨 공격 배율을 곱한다. 레벨 기본 체력은 체력 특성 배율 전에 더한다. 방어·쿨타임·지역 및 스킬 해금 조건은 바꾸지 않는다.
- 레벨 업은 새로 늘어난 최대 체력만큼만 회복하며 사망자를 부활시키거나 전량 회복시키지 않는다.
- 최고 레벨에서 경험치 바는 MAX로 표시한다. 장착 코스튬·아이템·펫·골드 저장 형태는 유지한다.
- 프로토콜의 `adventureLevel`은 펫 강화 수치 `level`과 분리하고 1~30 정수로 정리한다. 공격·HP 패킷에 같은 능력치 계약이 적용된다.

## 화면

- 캐릭터 상태: Lv, EXP 백분율·게이지. 가방: 정확한 EXP 수량.
- 목표 우선순위: 가방 190개 이상 → 미사용 특성 → 현재 지역 수련 보상 → 다음 지역 해금 → 반복 사냥 의뢰.
- 사냥 의뢰는 기존처럼 20마리마다 현재 주무기 종류 장비를 보장하며 목표에 남은 수량과 보장 등급을 표시한다.
- 목표 클릭은 가방·특성·NPC 대화로 연결한다. NPC의 거리·생존·연결 검사는 유지한다.
- 협동 현황은 메뉴를 열 때만 표시하며 다른 지역 플레이어와 자신은 제외한다. 파티 초대·길드·친구 기능으로 표시하지 않는다.
- 입장 중에는 목표 안내를 숨기며 자동 모달을 추가하지 않는다. 동료 상태 갱신은 250ms로 제한한다.

## 검증과 한계

- adventure-growth: 레벨별 경계·상한·기존 기록·이상 입력·중복 영수증·이벤트 중복·전투 수치·HP 패킷·목표 우선순위·지역 동료 필터.
- 기존 특성 배율 검사는 플레이어 Lv.1을 명시해 특성의 고정 수치를 검증한다. 레벨 스택은 별도 성장 검사에서 검증한다.
- room-startup: 캐릭터/지도 병렬 로딩, 미완료 NPC에 영향받지 않는 입장, 로딩 중 화면 이탈 회귀 유지.
- 접속 중인 구버전 호스트는 새 레벨 능력치를 이해하지 못할 수 있으므로 배포 후 같은 방의 참여자는 모두 새로고침해야 한다.
- 수신 수치의 범위 검사는 서버가 사냥 증거를 검증하는 부정행위 방지 기능을 대체하지 않는다. 전체 MMO 서버 권위 전환은 이 변경에 포함하지 않는다.
