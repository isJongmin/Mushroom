# 역할형 일반 몬스터 1차 적용

일반 몬스터의 차이가 체력과 접촉 피해에만 머물지 않도록 기존 몬스터에 세 가지 전투 역할을 부여했다. 별도 대용량 아트를 추가하지 않고 기존 시트와 절차적 그림 위에 예고 표시를 합성한다.

## 역할

- 돌진형: 광석 딱정벌레와 숲 그루터기. 노란 예고 원을 표시한 뒤 바라보는 방향으로 빠르게 돌진하며 접촉 피해가 1.5배가 된다.
- 방패형: 철갑 버섯과 광산 파수꾼. 가까운 플레이어를 향해 방패를 들고 정면에서 받는 피해를 70% 줄인다. 뒤쪽 공격은 그대로 들어간다.
- 폭발형: 슬라임 계열. 플레이어가 가까우면 예고 후 짧은 범위 폭발을 일으키며 접촉 피해가 1.7배가 된다.

## 멀티플레이 계약

호스트가 역할 상태를 결정하고 몬스터 스냅샷의 `a`(행동)와 `r`(남은 밀리초)로 전송한다. 허용 행동은 `windup`, `charge`, `guard`, `burst`로 제한하며 최대 3초만 받는다. 호스트 교체 시 최신 상태를 이어 받고, 구버전 패킷은 기존 접촉형 몬스터처럼 처리한다.

## 시각 언어

- 노란 원: 곧 특수 행동이 시작됨
- 주황 잔상: 돌진 중
- 청록 호: 방패가 막는 정면
- 붉은 원: 폭발 피해 범위

상태 표시는 Canvas `save/restore` 안에서만 그려 기존 아바타·맵 렌더링 상태를 오염시키지 않는다.
