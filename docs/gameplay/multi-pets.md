# 펫 최대 3마리 동행 (2026-11-03)

- 가방 → 펫에서 서로 다른 보유 펫을 최대 3마리 장착한다. 동행 슬롯별 해제와 교체가 가능하다. 같은 펫 중복 장착과 네 번째 장착은 막는다.
- 동행 중인 어느 펫이든 판매할 수 없다. 먼저 해당 슬롯의 동행을 해제해야 한다.
- `equippedPets`에 장착 ID를 저장한다. 기존 단일 `pet` 저장은 첫 슬롯으로 이관하고, 기존 장비/골드/정수/강화 수준을 보존한다. 기존 `pet`/`level`은 첫 펫의 호환 별칭으로 남긴다.
- 세 펫의 공격 보너스와 HP 보너스를 각각 합산하고, 그 뒤 모험 특성을 한 번 적용한다. 자동 줍기 범위와 보상 수량은 동행 수만큼 중복 적용하지 않는다.
- 원격 loadout의 `companions`에 최대 3개의 고유 ID와 강화 수준을 전달한다. 기존 단일 펫 패킷도 읽을 수 있다.
- 내 펫과 다른 플레이어의 펫 모두 같은 그룹 추적을 사용한다. 부드럽게 이동하는 그룹 중심 주위에 64 월드 픽셀 간격으로 배치하며, 방향 전환·아이템 수집 시 슬롯끼리 교차하거나 같은 좌표로 수렴하지 않는다. 각 플레이어가 소유한 동행 그룹 내부의 간격이다.
- 맵 이동/사망/동행 해제 시 추적 상태를 정리한다. 원격 추적기는 시야에서 사라진 플레이어에 대해 제거한다.

검증:

- 전체 JavaScript 테스트 26개 통과.
- 신규 `multi-pet.test.mjs`: 구형 저장 이관, 3마리 제한, 개별 해제/판매 보호, 합산 수식, 원격 공격/HP 패킷, 800프레임 방향 전환·아이템 수집·점프·맵 경계에서 최소 간격, 동시 마지막 슬롯 장착 및 저장 실패 롤백.
- 전용 로컬 테스트 캐릭터에 합성 펫 4종을 지급하고 실제 게임에서 3마리 분리 표시를 확인했다.
- 390px 모바일 가방에서 세 슬롯과 펫 목록이 겹치지 않고 표시되는 것을 확인했다.
- 실제 가방에서 네 번째 장착 비활성, 한 마리 해제 후 다른 펫 장착, 새로고침 후 세 슬롯 유지와 능력치 합산을 확인했다.
- 합성 데이터 QA는 뽑기로 실제 펫 4종을 획득한 장시간 플레이 검증이 아니다.
