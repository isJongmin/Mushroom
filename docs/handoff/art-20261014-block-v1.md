# art -> main: 스타일 전환 샘플 block_v1 (블록 캐릭터 4종 + 블록 지형)

날짜: 2026-10-14 / 담당: 아트
상태: 스타일 결정용 샘플. 기존 계약(32x48, 기준점 (16,46))과 기존 에셋은 건드리지 않았다. 통과하면 ARCHITECTURE "픽셀아트 계약"과 style-guide 5절을 아래 규격으로 개정해야 한다(디자인/메인 결정).

## 1. 규격

| 항목 | 값 |
|---|---|
| 프레임 | 48 x 64 px, 투명 배경, 알파 0/255만 |
| 기준점 | (24, 60) = 원점(두 발 사이 바닥 중앙, 깊이 z=0)의 투영 위치. 픽셀 열 23과 24 사이 선, 행 60의 윗선. 발 중앙 밑창 마지막 줄 y=59, 사선 투영 때문에 가장 앞쪽 발끝은 y=60까지 내려온다. 외곽선(C안)은 y=61까지 쓴다. 아래 2행 여백 |
| 배치 | 지면선 y에 서면 프레임 왼쪽 위 = (ax - 24, y - 60) |
| 캐릭터 크기 | 머리 정면 20x20 + 윗면 4px. 발~머리 위 43px(머리카락 포함 약 45px). 머리(머리카락 포함) 약 24px = 키의 약 53% |
| 시트 | 가로 한 줄 7프레임, 336 x 64: `front, side_idle, side_walk0..3, back` (프레임 i의 x = 48i) |
| 방향 | side는 오른쪽을 본다. 왼쪽은 프레임 좌우 반전(열 c -> 47 - c, 기준점 x=24 유지). 반전하면 광원도 반전되지만 블록 톤이라 어색하지 않다 |
| 걷기 | 150ms/프레임. walk0: 앞다리(카메라 쪽) 앞, 몸 1px 아래 / walk1: 교차, 뒷발 1px 들림, 몸 원위치 / walk2: 반대 / walk3: 교차. 다리 스윙 = 상자 전단(shear) 4px, 팔 3px |
| 투영 | 사선(oblique) A=0.2: sx = x + 0.2z, sy = y - 0.2z. 위·오른쪽에서 본 3/4. 보이는 면은 정면/윗면/오른쪽 옆면 |
| 면 톤 | 윗면 = 재질 밝은 톤, 정면 = 기본, 옆면 = 어두운 톤. 같은 레이어 안에서 다른 상자가 가까이 겹친 경계는 먼 쪽 1px을 한 톤 어둡게(팔/몸통, 턱 밑 구분) |
| 타일 | 16 x 16. 맨 위 4행 = 윗면(밟는 면), 그 아래가 정면 |
| 지면선 | 잔디 윗면 첫 행 + 2 (샘플 장면: 윗면 206, 지면선 208) |
| 표시 배율 | 아트 1px = 화면 2px (기존과 같은 정수 배율 규칙, `imageSmoothingEnabled = false`) |
| 장면 | 480 x 270 아트 px (2배 표시 시 960 x 540) |

## 2. 파일

소스 `assets/_src/block_v1/` (`python3 build.py [미리보기 폴더]`, 결정적: 난수 대신 좌표 해시 노이즈, 두 번 빌드 md5 동일 확인)
- `palette.py`: 스타일 가이드 42색 + 재질 램프(Mat: 밝음->어두움 리스트와 윗면/정면/옆면 인덱스, line 색)
- `render.py`: 상자 렌더러. `Box(x0,x1,y0,y1,z0,z1, layer, group, tex)`, 포즈(그룹별 이동 + 전단), 뷰 회전(front/side/back), 픽셀 중심 역사상 + z-buffer, 깊이 경계 그늘, 외곽선
- `chars.py`: 마네킹 치수, 파츠 정의(레이어별 상자 묶음과 텍스처 함수), 캐릭터 4종 조합, 프레임 포즈
- `scene.py`: 타일 4종, 소품(버섯 집, 나무, 구름, 블록, 꽃), 장면 조립
- `build.py`, `preview.py`

출력 `assets/_src/block_v1/out/`
- `avatar/<layer>/<id>.png`: 레이어 시트(외곽선 없음). 납품 기준 레이어
- `avatar/_composite/<char>.png`: A안 합성본(외곽선 없음)
- `avatar_silhouette/_composite/<char>.png`: C안 합성본(바깥 실루엣 외곽선). 최종 선택
- `avatar_outline/`: B안(레이어별 안쪽 외곽선). 비교용, 채택 안 함
- `avatar_manifest.json`: frame, anchor, frames, animations, layerOrder, parts, characters
- `tiles/grass.png, dirt.png, stone.png, plank.png`, `scene.png`(480x270)

## 3. 레이어 구조

합성 순서(모든 뷰 공통): `hair_back -> body -> face -> bottom -> shoes -> top -> hair_front -> hat`

| 레이어 | id (샘플) | 내용 |
|---|---|---|
| hair_back | 머리 id와 같음 | 머리카락 중 옷 입은 몸통/팔/다리 뒤에 있는 부분(정면의 긴 뒷머리 등). 빌드가 자동 분리 |
| body | skin_light | 머리, 몸통, 팔, 다리 상자 전체(피부). 손 = 팔 아래 3행 |
| face | basic | 눈 2x3(하이라이트 1px), 볼터치 2px, 입 2px. 정면 뷰는 앞면, 옆 뷰는 오른쪽 면 앞쪽에 눈 하나. 뒤 뷰는 비어 있음 |
| bottom | pants_navy, skirt_pink, pants_black, overalls_green | 다리 상자(신발 위 2행 제외), 치마는 몸통 그룹 |
| shoes | sneakers_white, maryjane_red, sneakers_red, boots_brown | 발 상자(앞으로 1 튀어나온 발끝) |
| top | hoodie_black, blouse_white, hoodie_white, overalls_green | 몸통 + 소매(+ 후드). 멜빵은 셔츠 위에 와야 해서 top으로 분류(셔츠+가슴판), 바지는 bottom |
| hair_front | black_short, pink_long, brown_short, blonde_short | 머리 큐브를 1px 감싸는 껍데기(앞면에 얼굴 창, 옆면 앞쪽 창) + 옆머리/리본 |
| hat | cap_white, mushroom_red | 모자. 머리카락 위에 그린다 |

레이어 독립성: 각 파츠는 혼자 렌더한 뒤, 공통 몸(body)이 더 앞에 있는 픽셀만 지운다(옆모습에서 카메라 쪽 손이 상의/치마를 가리는 자리 등). 다른 옷 파츠에는 의존하지 않으므로 어떤 조합도 같은 순서로 쌓으면 맞는다.
캐릭터 4종 조합은 `avatar_manifest.json`의 characters 참고.

## 4. 팔레트

스타일 가이드 42색만 사용(새 색 없음, 전 출력 PNG 검사 완료). 주요 재질 (윗면 / 정면 / 옆면 / line):
- 피부 s1 / s1 / s2 / w2. 눈 ink + white, 볼 p2, 입 w4
- 흑발 hb1 / hb2 / ink / ink. 검은 후드는 머리와 구분되게 한 톤 밝게 st2 / hb1 / hb2 / ink
- 분홍 머리/치마 p1 / p2 / p3 / p3. 밤색 머리 w2 / w3 / w4. 금발 y1 / y2 / y3 / y4
- 흰 원단(후드, 모자, 블라우스) white / c1 / c2 / c3. 네이비 u3 / u4 / ink. 검은 바지 hb1 / hb2 / ink. 초록 g1 / g2 / g3 / g4
- 버섯 갓 r1 / r2 / r3, 점 white / c1. 기둥 c1 / c1 / c2. 돌 st1 / st2 / hb1. 나무 w1 / w2 / w3 / w4. 잎 g1 / g2 / g3
- 하늘 띠 k1~k5, 먼 언덕 m1/m2, 구름 white / k5

## 5. 외곽선 결정: C안(합성본 바깥 실루엣 1px)

`outline_compare.png`에서 캐릭터 1, 3을 비교했다(A 없음 / B 레이어별 안쪽 / C 합성 바깥 실루엣).
- A(없음): 가장 깔끔하고 마인크래프트다운 블록 느낌. 다만 흰 모자·흰 후드가 밝은 배경에서 경계가 흐려진다.
- B(안쪽): 1px 선이 3행짜리 손과 얼굴 창 가장자리를 먹어서 지저분하고 작아 보인다. 탈락.
- C(바깥 실루엣): 내부는 A 그대로 3면 톤으로 깔끔하고, 바깥만 재질의 line 색으로 감싸 언덕/하늘/잔디 위에서도 캐릭터가 바로 읽힌다. 장면에서 가장 귀엽고 정돈돼 보였다.

구현 방식: 레이어 PNG는 외곽선 없이 납품한다(레이어 정렬이 깨지지 않게). 프런트가 아바타를 오프스크린 48x64 캔버스에 합성한 뒤, 투명 픽셀 중 4방향 이웃에 불투명 픽셀이 있으면 그 이웃 재질의 line 색으로 칠한다(이웃 탐색 순서 아래, 왼쪽, 오른쪽, 위). 재질 정보 대신 쓸 수 있는 근사: 이웃 색의 램프 최암색 매핑 표를 아트가 JSON으로 제공 가능. 합성 결과는 외형 조합이 바뀔 때만 다시 만들면 된다. 빌드 스크립트의 `silhouette()`가 기준 구현이다.

## 6. 회차 기록

1. 첫 렌더: 블록 비율과 3면 톤은 바로 성립. 문제: 머리카락 노이즈가 소금후추처럼 지저분함, 팔이 몸통과 같은 색이라 한 덩어리, 분홍 옆머리가 옆모습에서 얼굴을 덮음, 모자 크라운이 너무 높아 요리사 모자처럼 보임, 후드 주머니가 카메라 모양으로 읽힘.
2. 노이즈를 면별로(윗면은 밝은 점 6%, 정면/옆면은 어두운 점 4%) 줄임. 같은 레이어 안 깊이 경계 그늘 추가(팔/몸통, 턱 밑). 모자 크라운 10 -> 7행, 주머니 제거, 눈 1행 내림. 외곽선 A/B 비교: B 탈락.
3. 옆모습 얼굴이 너무 작음 -> 머리 껍데기 옆면 창을 머리 앞쪽 절반까지 넓힘. 분홍 옆머리를 뒤쪽 짧은 블록으로, 걷기 스윙 다리 3 -> 4px, 팔 2.5 -> 3px. C안(합성 실루엣) 추가.
4. 뒷모습 목덜미 피부 띠 2 -> 1행, 분홍 뒷머리를 2단 계단 + 가르마 결로 쪼갬. 장면 제작: 흙 반점 밀도 낮춤, 꽃을 4x3 블록 꽃으로 키움.
5. 프레임 경계 점검: 기준점 y=62에서는 발끝이 62, C안 외곽선이 63(프레임 끝)에 닿아 기준점을 (24, 60)으로 올림. 팔레트/알파 검사, 결정적 빌드 확인.

| 항목 | 점수 | 근거 |
|---|---|---|
| 한눈에 귀여움 | 7 | 큰 머리 큐브 + 2x3 눈 + 볼터치는 확실히 귀엽다. 표정이 하나뿐이고 정면 얼굴이 조금 단조롭다 |
| 블록 느낌 | 9 | 모든 부위가 상자이고 3면 톤 + 깊이 경계 그늘이 일관된다 |
| 비율 | 8 | 머리 약 53%, 짧은 몸통과 다리. 요청 45~50%보다 약간 크지만 귀여움 쪽으로 판단 |
| 깔끔함(깨진 픽셀) | 8 | 역사상 렌더라 구멍이나 겹침이 없다. 머리카락 노이즈 점은 취향에 따라 더 줄일 여지 |
| 옆/뒤 뷰 | 6 | 옆모습은 머리 옆면이 대부분 머리카락이라 얼굴이 작다. 분홍 긴 머리의 뒷모습은 여전히 큰 판 느낌 |
| 걷기 | 6 | 전단 스윙 + 1px 바운스로 걷는 게 읽히지만, 다리가 겹쳐 6배에서도 발 두 개 구분이 약하다 |
| 커스터마이징 시연 | 8 | 머리 4, 모자 2, 상의 4, 하의 4, 신발 4가 같은 프레임/기준점에서 섞인다 |
| 지형 장면 | 7 | 스케일 확인용으로 충분. 흙 영역이 넓고 단조롭고 꽃이 여전히 작다 |

## 8. 전체 제작 시 고려사항

- 계약 개정 필요: 프레임 32x48 -> 48x64, 기준점 (24,60), 시트 6 -> 7프레임(뷰 3종 + 걷기 4), 레이어 5 -> 8종(hair 하나가 hair_back/hair_front 두 시트), 아바타 data 키에 `hat`, `face`, `shoes` 추가. 기존 DB id 매핑 표 필요.
- idle 숨쉬기 프레임이 없다(요청 범위 밖). 필요하면 front/side에 몸 1px 바운스 idle1 추가.
- 왼쪽 보기는 반전으로 처리. 비대칭 소품(리본, 로고)이 반전된다. 문제가 되면 side_left 시트 4프레임을 추가로 렌더하면 된다(뷰 회전만 바꾸면 됨).
- 피부 톤 추가는 skin 재질만 바꾸면 모든 프레임에 적용된다(보통/진한 피부 램프는 스타일 가이드에 있음).
- 맵: 지면선을 타일 윗면 + 2로 두면 발이 윗면 가운데에 선다. 기존 월드 규격(지면 아트 y 220)에 맞추려면 잔디 윗면 첫 행을 218에 둔다.
- 텍스트(닉네임/말풍선)는 기존처럼 화면 해상도로 그린다. 캐릭터 머리 위 공간: 버섯 모자 기준 머리 꼭대기 y=8(프레임 기준).
- 프런트 렌더 비용: 합성 + 실루엣 외곽선은 외형이 바뀔 때 한 번만 계산해 캐시(아바타당 336x64 캔버스 1장).
