## 3. 프런트 참조 값

아바타 (`assets/avatar/manifest.json`, 계약 형식 + 추가 키 2개):
```json
{ "frame": {"w":32,"h":48}, "anchor": {"x":16,"y":46}, "scale": 2,
  "layerOrder": ["skin","bottom","top","eyes","hair"],
  "frameOrder": ["idle0","idle1","walk0","walk1","walk2","walk3"],
  "animations": {"idle":{"frames":[0,1],"ms":500}, "walk":{"frames":[2,3,4,5],"ms":120}},
  "parts": { "skin": [{"id":"skin-light","label":"밝은 피부"}, ...], "hair": [...], "eyes": [...], "top": [...], "bottom": [...] },
  "aliases": {"eyes-round":"eyes-sparkle", "top-vest-green":"top-overalls-blue"} }
```
- 시트 경로: `assets/avatar/<part>/<id>.png`, 프레임 i = x `32*i`. 각 part 배열 첫 항목이 기본값 (style-guide 5.10 순서).
- 기준점 (16,46): 발바닥 마지막 줄 y 45, 행 46–47 투명. 왼쪽은 시트를 x=16 기준 좌우 반전(열 c → 31-c). 발 그림자는 프런트가 그린다 (4.5).
- `aliases`에 없고 목록에도 없는 id는 part 기본값.

맵 (`assets/map/manifest.json`): style-guide 6.1 예시와 값 동일 (sky 0/0.0, clouds 18/0.25, mountains 110/0.2, hills 142/0.3, trees 104/0.5 = repeatX, village 60/1.0, ground 216/1.0). village 마지막 불투명 행 159 (아트 y 219), ground 행 4 = 아트 y 220 잔디 윗면.

UI (`assets/ui/manifest.json`): style-guide 7.1 형식 그대로. `nine.*.slice` [위,오,아래,왼], 버튼 `pressedShift: 2`, `button-secondary.states.disabled` = `button-primary-disabled.png`. sprites: `bubble-tail`, `icon-mushroom`, `icon-arrow`.

## 6. 알려진 문제 / 디자인 확인 요청

1. 머리 정본 격자(5.7.1)와 5.4 "hair 눈 상자 금지"가 충돌: `round`/`long`의 (21,15), `spiky`의 (14,15)가 눈 상자 첫 줄(눈썹 줄)에 있다. 금지 규칙을 우선해 그 픽셀을 지우고 외곽선을 다시 계산했다 (반짝 눈 앞눈썹 x21이 가려지지 않음). 디자인이 격자를 고쳐 주면 좋겠다.
2. 버섯 집 창 위치 "(기둥 중심 +10, 기둥 위 +12)"를 창의 중심으로 해석했다. 왼쪽 위로 해석하면 집 B, D에서 창이 기둥 밖으로 나간다.
3. 산 높이: 6.3 "높이 45–85"와 "가장 높은 봉우리가 이미지 위 끝 근처"가 맞지 않아 시안과 같이 바닥 20 + 봉우리 40–84 (최고 104/110)로 그렸다.
4. walk2 앞팔이 몸통 위를 지나는 프레임은 같은 색 상의(빨강 티, 파랑 후드)에서 소매 외곽선으로만 구분된다. 영역 지도대로이며 120ms 프레임이라 실제 재생에서는 자연스럽다 (`walk.gif`).
5. 프런트가 아직 SVG 경로를 참조하면 깨진다 (SVG 삭제 완료). `src/client`는 건드리지 않았다.
