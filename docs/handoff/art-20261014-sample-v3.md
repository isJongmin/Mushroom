# art → main: 품질 기준 샘플 v3 (검은 후드 소년 1명)

날짜: 2026-10-14 / 담당: 아트
상태: 품질 확인용 샘플. 기존 계약(32x48, 기준점 (16,46))과 별개이며, 기존 에셋은 수정하지 않았다.

## 1. 규격

| 항목 | 값 |
|---|---|
| 프레임 | 80 x 96 px, 투명 배경 |
| 기준점 | (40, 92): 신발 밑창의 마지막 불투명 행이 y=92. 지면 y에 frame.y = ground - 92 로 배치 |
| 캐릭터 키 | 머리카락 위 y=7 ~ 발 y=92 = 86px (바보털 포함 y=3, 90px) |
| 머리 비율 | 머리카락 위 7 ~ 턱 55 = 49px / 86px = 약 57% |
| 프레임 순서 (sheet.png, 560x96 가로) | front, side_idle, side_walk0, side_walk1, side_walk2, side_walk3, back |
| 방향 | side는 오른쪽을 본다. 왼쪽은 x=40 기준 좌우 반전 (프레임 전체를 뒤집으면 됨) |
| 걷기 | 프레임당 150ms 권장. walk0/2 = 접지(몸 1px 아래), walk1/3 = 교차(몸 원위치, 뒷발 2px 들림) |
| 색 | 37색 (palette.py, 문자 1개 = 색 1개). 알파는 0 또는 255만 |
| 광원 | 왼쪽 위. side를 반전하면 광원도 오른쪽 위가 된다 (허용 범위로 판단) |

## 3. 레이어 구조

합성 순서: `hair_back → body → bottom → shoes → top → eyes → hair_front`

| 레이어 | 내용 |
|---|---|
| hair_back | 머리 덩어리 중 얼굴과 겹치지 않는 부분 (뒤통수, 옆 볼륨). 귀가 그 위에 얹힌다 |
| body | 얼굴, 귀, 목, 손, 다리(정강이), 볼터치 |
| bottom | 반바지 |
| shoes | 운동화 |
| top | 후드티 (몸통, 후드, 끈, 주머니, 소매). 손이 보여야 하는 자리는 투명하게 비워 둔다 |
| eyes | 눈 + 입 (표정 교체 단위로 묶음) |
| hair_front | 앞머리와 얼굴 위 옆머리. back 뷰에서는 머리 전체 (후드를 덮어야 하므로) |

머리는 한 번에 그린 뒤(셰이딩·외곽선 일관성) 얼굴 확장 마스크로 hair_back / hair_front를 나눈다.

## 4. 반복 기록

1. 첫 렌더: 머리 실루엣이 삼각 돌기 위주라 뿔처럼 보임, 가닥선이 정수리 한 점에서 방사형으로 과다, 얼굴 노출이 크고 그림자 톤 위주로 탁함, 측면 얼굴창이 귀 뒤까지 열려 귀가 얼굴 한가운데 박힘, 측면 반바지 가늘고 몸통 좁음, 눈 작음.
2. 실루엣을 타원 + 둘레 둥근 혹(lumpy) 방식으로 교체, 앞머리 끝을 눈 위까지 내림, 눈 8x10에 2줄 윗 속눈썹, 측면 얼굴을 x>=41로 제한하고 귀를 hair_back 위로, 측면 몸통·반바지 확대, 피부 팔레트 밝게.
3. 얼굴에 대각 하이라이트 띠가 생김 → 평면 셀 셰이딩(오른쪽·턱 아래·앞머리 그늘만)으로 교체. 머리 하이라이트를 매끈한 호에서 엇갈린 짧은 대시 2줄로. 측면 볼 돌출 타원 추가, 정면 신발 둥글게, 후면 목덜미 끝 불규칙하게.
4. 참고 이미지 대비 머리가 너무 검고 납작함 → 머리 램프 밝힘 + 중간톤(K) 추가해 빛 받는 넓은 영역 표현, 가닥선은 하이라이트 띠 아래부터만 진하게, 혹 개수·크기 축소(곱슬처럼 보이던 문제), 측면 후드 축소.
5. 정면 옆머리 뿔 돌기 제거, 정수리 돔 형태로, 턱을 좁힌 얼굴형, 삐친 머리를 실루엣에 붙임. 걷기에서 손이 상의에 가려 팔 스윙이 안 읽혀 손 자리 컷아웃 추가, 엉덩이 블록 축소로 다리 교차가 보이게. 앞팔 림라이트, 측면 입 위치, 정면 손 1px 내림.

## 6. 전체 파츠로 확장할 때 예상되는 문제

- **크기 불일치**: 80x96 캐릭터는 world-1x 맵의 집(약 80px)보다 크다 (`ingame.png`). 이 해상도를 채택하면 맵을 2배로 다시 그리거나 아바타 표시 배율을 1/2로 해야 한다. 디자인/메인 결정 필요.
- **머리 스타일별 hair_back 필수**: 긴 머리(참고 시트의 은발·분홍)는 몸통 뒤로 내려가므로 hair_back이 top보다 뒤에 있어야 하고, 반대로 짧은 머리 back 뷰는 후드를 덮어야 해서 hair_front가 필요하다. 스타일마다 두 레이어 분할 규칙을 따로 정해야 한다.
- **앞머리 그늘**: 이마 그늘(y<=36)을 body에 고정으로 넣었다. 앞머리가 짧은 스타일에서는 줄무늬로 보일 수 있어, 그늘을 hair_front 쪽 '피부 그늘 색' 픽셀로 옮기려면 피부색마다 hair_front 변형이 필요해진다.
- **측면 눈**: 측면 눈은 정면 눈과 다른 그리드다. 눈 파츠 하나당 front/side 두 그리드가 필요하고, 표정 교체 시에도 두 벌.
- **손 컷아웃**: top 레이어가 손 자리를 비운다. 상의를 바꿔도 손 마스크는 공통이어야 하므로, 손 위치를 프레임별 상수로 계약에 넣어야 한다.
- **좌우 반전**: 광원이 반대로 뒤집힌다. 문제가 되면 왼쪽 프레임을 따로 그려야 한다 (시트 2배).
- **팔레트**: 캐릭터 하나에 37색. 파츠 색상 변형(머리색 5종 등)을 하면 기존 42색 공용 팔레트로는 부족하다. 재질별 램프 교체(팔레트 스왑) 방식으로 정해야 한다.
- **제작량**: 생성 스크립트는 형태 데이터(다각형, 가닥선)를 손으로 지정해야 해서 머리 스타일 1종 x 3뷰에 반복 조정이 여러 번 필요했다.
