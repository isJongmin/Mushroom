# art -> main/front: 복셀 맵 "버섯마을 낮" (사이클 5)

날짜: 2026-10-15 / 담당: 아트(맵)
상태: **납품**. `assets/map/` 을 복셀 조명 렌더 맵으로 교체(이전 블록 맵 PNG 삭제). 계약: ARCHITECTURE "복셀 아트 계약"(밀도 1.5px = 월드 1, 월드 2400x540, 지면선 y=440).

## 1. 빌드

```
python3 assets/_src/voxel_map/build.py                     # 5개 레이어 + manifest (약 5분, 2코어)
python3 assets/_src/voxel_map/build.py --only ground       # 한 레이어만
python3 assets/_src/voxel_map/build.py --raw DIR           # 렌더 원본 PNG도 DIR에 저장
python3 assets/_src/voxel_map/preview.py OUT [CHAR_DIR]    # map_full / view_desktop / with_char(_p3) 미리보기
python3 assets/_src/voxel_map/check.py [--determinism]     # manifest-파일 일치, 크기, 용량, 이음매, 결정성
```

소스 `assets/_src/voxel_map/`:
- `vox.py` — `assets/_src/voxel_v1/vox.py` 복사본을 맵용으로 확장. 조명 방향/색, AO 색, 베벨, 림, 톤맵은 캐릭터와 같다. 추가: 레이어별 설정(Cfg: 슈퍼샘플 3x3, 점유 격자 1단위, AO 반경, 그림자 레이 길이, 지면 반사광, 하늘 필, 따뜻한 색 보정 1.06/1.0/0.91), 발광(emit) + 후처리 글로, 깊이별 공기 원근(haze), 세로 띠 타일 렌더(2코어 병렬, 타일마다 좌우 여유 + 그림자 방향 여유만큼 상자를 포함해 그림자/AO가 타일 경계를 넘어 이어짐).
- `props.py` — 소품 복셀 모델(버섯 집, 참나무, 벚꽃, 소나무, 가로등 랜턴, 울타리, 우물, 표지판, 벤치, 덤불, 꽃, 풀, 돌, 작은 버섯, 통, 상자).
- `scene.py` — 지면 레이어(잔디 블록 윗면 14줄 + 앞 단면 흙/돌 + 소품 배치표).
- `layers_bg.py` — sky(그라데이션), clouds, far, mid.
- `build.py`, `preview.py`, `check.py`.
- 결정적 출력: 난수는 고정 seed `default_rng` 와 좌표 해시만. 전체 빌드 2회 md5 동일 확인, `check.py --determinism` 통과.
- 반복 레이어는 상자를 주기만큼 좌우 복제해 렌더하므로 이음매가 기하적으로 이어진다(검사: 끝-처음 열 차 0.05~0.56, 이웃 열 평균 수준).

## 2. 레이어 (`assets/map/manifest.json`, 앞쪽 항목이 뒤에 그려짐)

| 파일 | parallax | y(월드) | px 크기 | 월드 크기 | repeatX | stretchX | 용량 |
|---|---|---|---|---|---|---|---|
| sky.png | 0 | 0 | 16x810 | 10.7x540 | false | **true** | 3 KB |
| clouds.webp | 0.12 | 10 | 2700x330 | 1800x220 | true | - | 29 KB |
| far.webp | 0.3 | 120 | 3000x480 | 2000x320 | true | - | 318 KB |
| mid.webp | 0.65 | 170 | 3000x405 | 2000x270 | true | - | 402 KB |
| ground.webp | 1.0 | 110 | 3600x645 | 2400x430 | false | - | 786 KB |
| 합계(manifest 포함) | | | | | | | **1.54 MB** (한도 6 MB) |

- WebP는 **무손실**(손실 WebP는 가장자리 블록 오차로 반복 이음매가 튀었다). 반투명 가장자리 알파 포함, RGBA.
- manifest 항목: 계약 필드(`src, parallax, y, repeatX, stretchX`) + 참고용 `name, w, h`(월드 단위 = px/1.5).
- 맨 위: `{"density":1.5, "groundY":440, "width":2400, "layers":[...]}`.
- 선택 레이어 front 는 넣지 않았다(캐릭터 발 가독성 우선).

## 3. 구성

- 카메라: 모든 레이어 직교, yaw 0, pitch 15(위에서 약간 내려다봄, 잔디 윗면이 보임). 조명은 캐릭터와 같은 키라이트(위-앞-왼쪽, 따뜻) + 하늘 필 + AO + 소프트 섀도 + 베벨 + 림. 소품은 개별로 ±14~20도 돌려 옆면이 보인다.
- **ground**: 모델 1단위 = 월드 2 = 3px. 원점 = 월드 (0, 440) = 캐릭터가 걷는 선(깊이 z=0). 잔디 윗면은 z +12(앞 가장자리, 화면 월드 y≈446) ~ -104(뒤, y≈386). 앞 단면(흙→아래로 갈수록 돌, 아래로 갈수록 어두움)이 y 446~540. 소품은 모두 z -20 이하(걷는 선 뒤)에 있어 캐릭터를 가리지 않는다. 걷는 선 y=440 행은 전 구간 불투명 잔디(check.py 검사).
  - 소품(x는 월드): 참나무(44, 1540, 2372), 빨강 버섯 집(300), 작은 버섯, 랜턴(460, 768, 1448, 2136), 꽃밭+울타리(540), 벚꽃(672, 2208)+떨어진 꽃잎, 우물(864), 돌, 벤치(1000), 주황 버섯 집(1188, 중앙), 표지판(1328), 작은 버섯들, 덤불/돌/울타리(1600~1760), 파랑 버섯 집(1904), 통/상자, 뒤 가장자리 덤불 띠, 풀 술 46개, 꽃 다발.
  - 버섯 집: 크림 기둥(팔각) + 7단 둥근 갓 + 흰 점(앞/옆/윗면) + 아치 나무 문 + 따뜻하게 빛나는 창 3~4개(어깨 2, 옆 1, 다락 1) + 창턱 꽃 + 굴뚝 + 디딤돌. 높이 약 월드 200~250(캐릭터 약 100).
- **mid**(1단위 = 월드 1.5): 계단식 초록 언덕 2줄, 숲 줄(둥근 나무/소나무/벚꽃), 언덕 위 오두막 3채(창 발광). 공기 원근 27%.
- **far**(1단위 = 월드 1): 먼 봉우리 8개(눈 덮인 꼭대기), 초록 언덕, 절벽 위 성(파란 고깔 탑 4개), 떠 있는 섬(나무, 작은 버섯 집, 폭포), 호수 띠(대부분 mid에 가림). 공기 원근 22~56%(깊이에 따라).
- **clouds**(1단위 = 월드 2): 큐브 적운 8개(3가지 크기), 아랫면 그늘, 약한 공기 원근.
- **sky**: 위 진한 하늘색 #4FA6E8 → 하늘색 → 지평선 쪽 크림 #F4EBD8 / 살구 #FFE2BC(월드 y 약 350 아래). 4x4 순서 디더로 8비트 띠 방지.

## 4. 프런트 구현 포인트

- **밀도 환산**: 이미지 px / 1.5 = 월드 단위. 화면 그리기 크기 = 월드 크기 x (P/2). 예: ground 3600x645px → 월드 2400x430 → P=2에서 화면 2400x430, P=3에서 3600x645(1:1).
- 위치: 레이어 윗변 월드 y = manifest `y`(현재 코드처럼 `- camY`). x 오프셋 `ox = -floor(camX * parallax)`(월드 단위), repeatX면 월드 너비 `w`(= px/1.5) 주기로 시야 끝까지 반복.
- **stretchX**(sky): 가로로 시야 전체 너비에 늘려 그린다(parallax 무시). 세로는 월드 540 = 810px 그대로 (P/2 배율). 16px 폭이라 가로 보간만 일어난다.
- **스무딩**: `imageSmoothingEnabled = true`, `imageSmoothingQuality = 'high'`(P=2에서 2/3 축소). NEAREST로 그리면 계단이 생긴다.
- 지면 레이어 판별(현재 assets.js: 마지막 parallax 1 & repeatX false) 그대로 동작. 지면 레이어 y=110이며 윗부분(소품 위쪽)은 투명.
- 캐릭터 기준점(발)을 y=440에 놓으면 잔디 윗면 위, 앞 가장자리(446)보다 6단위 뒤에 선다. 기존 발 그림자(`drawFootShadow`)는 그대로 써도 되지만 맵 자체에 소품 그림자가 있으므로 반투명 타원(알파 0.25 정도)을 권장.
- `assets.js` 의 manifest 읽기가 아직 사이클 4 형식(`scale`, groundY 220)을 기대하면 `density`/월드 단위 형식으로 갱신 필요(프런트 담당).
- 이전 파일 `sky.png, clouds.png, far.png, mid.png, ground.png`(블록 맵)는 삭제됨. 현재 이름: `sky.png` + `*.webp`.

## 5. 회차 기록 (미리보기: 스크래치 `voxelmap/`)

1. 소품 단독 렌더: 집 갓이 피라미드처럼 좁고 기둥이 탑처럼 높음, 나무 잎이 작고 줄기가 김, 벚꽃이 흩어진 상자 덩어리, 랜턴 가늘음. 갓 그늘 아래 기둥이 회색으로 탁함 → 지면 반사광(bounce) 1.9배 추가, 나무 잎 반경 키움, 랜턴 굵게.
2. 전체 첫 합성: 분위기/스타일은 캐릭터와 잘 맞음. 앞 단면 흙/돌이 너무 밝고 시끄러움, 집이 작고 탑 모양, 구름이 납작한 2단 상자, 성이 mid 숲에 가려 안 보임, 먼 산이 막대그래프. → 집 비율 재설계(넓고 낮은 기둥 + 7단 넓은 돔 갓, 1.1~1.28배), 벚꽃 층층 돔 + 표면 꽃송이, 앞 단면 어둡게 + 돌 비율 축소 + 깊이별 감광, 먼 산을 봉우리별 층으로, 성을 절벽 위로 올림, 섬 확대, 따뜻한 색 보정.
3. 구름이 세로 기둥(티슈 상자)처럼 나옴 → 2단 퍼프 적운으로 다시 짬. 폭포 넓힘, 랜턴 발광/글로 강화, 먼 산 색 조정.
4. 집 창문이 벽 속에 묻혀 창턱만 보임(좌표 버그) → 각 면 바로 앞으로 이동, 다락 창 추가. 하늘 따뜻한 띠를 위로 올리고 mid 공기 원근 증가로 깊이 분리.
5. 잔디 윗면 단조로움 → 저주파 진한/밝은 잔디 패치. 손실 WebP 반복 이음매 오차 발견 → 무손실 WebP로 전환. 최종 빌드 2회 md5 동일, check.py 통과.

## 7. 알려진 문제 / 다음 후보

- 앞 단면이 화면 아래 약 18%를 차지한다(월드 446~540). UI 채팅 입력창이 아래에 겹치면 덜 중요하므로 괜찮지만, 더 좁히려면 groundY 계약 변경이 필요.
- 원경의 호수는 mid에 거의 가려 보이지 않는다(효과 미미).
- 랜턴 빛은 낮이라 은은한 수준. 밤 맵을 만든다면 같은 장면에 조명 프리셋만 바꿔 다시 구우면 된다(emit 강도, 키라이트 색).
- 렌더 시간: 지면 약 140초, mid/far 각 약 65초, 전체 약 5분(2코어).
