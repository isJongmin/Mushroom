# art -> main: voxel_v1 샘플 (3D 복셀 모델 + 조명 렌더 스프라이트)

날짜: 2026-10-15 / 담당: 아트
상태: **샘플 (품질 확인용)**. 기존 `assets/avatar`, `assets/map`, `assets/_src/block` 은 건드리지 않음. 게임 계약(48x64 블록 아트)과 별개.

## 1. 방법

- `assets/_src/voxel_v1/vox.py` — numpy 직교 레이캐스터. 모델 = 방향 있는 상자(Box) 목록. 상자 하나가 "큐브 덩어리" 하나(베벨·이음새 단위).
  - 1차 가시성: 해석적 ray-box(slab) 교차, 4x4 슈퍼샘플 후 박스 필터 다운샘플 (가장자리 반투명 알파).
  - 조명(카메라 기준으로 고정해 모든 뷰가 같은 방향에서 빛을 받음): 따뜻한 키라이트(위-앞-왼쪽) + 소프트 섀도, 하늘 필(위), 지면 반사(아래), 차가운 정면 필, 따뜻한 백라이트(뒤-오른쪽).
  - 그림자/AO: 포즈마다 0.5단위 점유 격자(뷰 공간)를 만든다. 그림자 = 지터 원뿔 레이 마칭 투과율, AO = 26방향 x 4반경 반구 샘플. AO 색은 따뜻하게 틀어 피부 그늘이 탁하지 않게 했다.
  - 큐브 느낌: 상자 가장자리 0.38단위 안에서 법선을 바깥으로 기울여(베벨) 모서리가 빛을 받는다. 셀 단위 해시 노이즈로 미세 결(머리카락 7%, 옷 4%).
  - 림: 깊이 버퍼 기준 화면 공간 오른쪽-위 가장자리 발광.
  - 톤맵: 0.78 이상만 부드럽게 눌러서 흰 옷이 회색으로 죽지 않게 했다.
- `model.py` — 마네킹(뼈: root/torso/head/arm±/leg±) + 파츠 함수 + 프레임 포즈. 얼굴은 머리 앞면에 붙인 얇은 데칼 상자(눈 4.6x7칸, 하이라이트 2x2 + 1x1 반사점, 볼터치, 입).
- `build.py` — 정답(전체) 렌더, 레이어별 렌더, 그림자 레이어, 합성 검증, manifest, timing. `preview.py` — 미리보기.
- 결정적 출력: 난수는 고정 seed의 `default_rng` 와 좌표 해시만 사용. 같은 명령을 다시 돌리면 같은 md5 (확인함).

```
python3 assets/_src/voxel_v1/build.py                 # out/ 전체 (약 2분 30초, 2코어)
python3 assets/_src/voxel_v1/build.py --preview DIR   # + compare/sheet_3x/walk.gif/swap/ingame
python3 assets/_src/voxel_v1/build.py --quick         # 기본 조합 하나만
```

## 3. 레이어 분리 방식 (교체 검증 완료)

합성 순서: `hair_back, skin, face, bottom, shoes, shade_top, top, shade_hair, hair_front`

1. **마네킹 깊이 마스크**: skin 레이어 = 마네킹(머리, 목, 몸통, 팔, 손, 다리) 전체. 다른 파츠는 `마네킹 + 자기 상자`만 놓고 렌더한 뒤, 마네킹이 앞에 있는 픽셀을 투명하게 만든다. 다른 옷/머리와는 무관하므로 어떤 조합이든 순서대로 쌓으면 맞물린다. 예를 들어 걷기에서 먼 쪽 팔이 가까운 다리 뒤로 들어가는 것도 마네킹 마스크로 해결된다.
2. **조명 베이크**: 각 파츠의 AO/그림자는 `마네킹 + 자기 상자` 기준으로 굽는다. 다른 파츠에 의존하지 않는다.
3. **그림자 레이어 `shade_<cat>`**: 파츠가 다른 곳에 드리우는 그림자(앞머리가 이마에, 머리카락이 어깨에, 후드티 밑단이 바지에)는 별도 PNG로 납품. 마네킹 표면 조도를 `파츠 있음/없음` 비율로 계산해 A = 어두워짐, RGB = 그림자색 #221A30으로 만든다. 프런트는 `globalCompositeOperation = 'source-atop'` 으로 그린다(이미 그려진 픽셀에만 덮임).
4. hair는 상자마다 `back` 플래그. front/side 뷰에서는 hair_back(목 아래로 내려가는 뒷머리), back 뷰에서는 전부 hair_front(뒷모습에선 뒷머리가 등 앞에 있음). 프레임 단위로 소속이 바뀐다.

검증 (`out/timing.json`, swap.png): 레이어 합성과 전체 렌더의 차이, 8프레임 평균.

| 조합 | 평균 RGB 차 /255 | p95 | 알파 차 |
|---|---|---|---|
| A 곱슬+흰 후드 | 3.4 | 20 | 0.05 |
| B 곱슬+노란 티 (상의 교체) | 3.0 | 16 | 0.04 |
| C 웨이브+흰 후드 (머리 교체) | 3.8 | 17 | 0.06 |
| D 웨이브+노란 티 (둘 다 교체) | 3.4 | 15 | 0.07 |

눈으로 보면 구분되지 않는다. 남은 차이는 머리 옆선의 림 1px, 그림자 레이어가 마네킹 표면 기준이라 옷 표면(0.5칸 바깥)과 약간 어긋나는 부분이다.

## 5. 회차 기록

1. 첫 렌더. 비율과 큐브 느낌은 나왔으나 머리가 적갈색이고 자갈처럼 잘게 쪼개졌다. 뒷머리가 평평한 벽, 피부가 창백한 회색, 톤맵 때문에 흰 옷이 회색, 키라이트가 얼굴 앞면을 비껴감, side yaw 78이라 얼굴이 안 보임.
2. 머리를 큰 판 덩어리 기와 구조로 다시 짰다(정수리 4x4, 앞머리 2겹 가닥, 옆 3단, 뒤 4단, 바깥 삐침 8개). 거의 검정 #30231F. 피부를 따뜻하게(#FAD3BA), 눈을 키움(4.6x7칸), 톤맵 교체, 키라이트를 정면 쪽으로, side yaw 62, 후드 덩어리를 키우고 뒤로 뺐다.
3. 앞머리 그림자가 이마에 안 생겨서 키라이트를 높이고 AO 반경 4.6과 강도를 올렸다. AO 색을 따뜻하게, 림 강도 x1.7. 하늘 필을 덜 파랗게 해서 눈 하이라이트가 하늘색으로 뜨던 문제를 고침. 몸통/어깨 폭을 늘림(머리 대비 몸이 빈약했음).
4. 곱슬머리가 벽돌담처럼 규칙적이라 덩어리 크기/위치/높이를 불규칙하게 바꿨다. 웨이브 머리 뒷면을 엇갈린 기와로 바꾸고, side에서 떠 보이던 옆 덩어리를 정리.
5. 최종 확인: sheet/walk/swap/ingame 확인, 결정적 빌드 확인.

## 7. 게임 적용 시 고려사항

- **맵 스타일 통일**: ingame.png에서 맵은 선명한 2x 픽셀아트, 캐릭터는 부드러운 조명 렌더라 이질감이 있다. 같이 가려면 맵 소품/타일도 같은 렌더러로 굽거나(상자 모델로 쉽게 표현 가능), 캐릭터 렌더를 저해상도(48x64)로 렌더한 뒤 NEAREST 2x로 표시해 픽셀 느낌을 맞추는 두 방향이 있다. 후자는 별도 테스트가 필요하다.
- **해상도/배율**: 96x128 @1x는 기존 48x64@2x와 같은 화면 크기다. 다만 캐릭터가 더 커 보인다(키 약 108px 대 86px). 맞추려면 SCALE 2.1을 1.8 정도로. 3x 화면(1600x900 이상)에서는 1.5배 확대해야 하므로 흐려진다. 144x192 고해상도 시트를 따로 뽑는 것이 낫다(렌더 시간 약 2.3배).
- **계약 변경 필요**: 프레임 96x128, 기준점 (48,120), 반투명 알파 허용, 외곽선 규칙 폐지 또는 변경, `shade_*` 레이어와 source-atop 합성, 8프레임 순서. ARCHITECTURE의 블록 아트 계약 개정이 필요하다(메인/디자인 결정).
- **파츠 전체 제작 비용**: 파츠 하나 = 코드로 상자 20~80개. 머리카락 하나에 30~60분, 옷 15~30분 정도. 기존 47개 파츠를 옮기면 모델링이 하루 이틀 걸린다. 렌더는 파츠 x 8프레임 x 1.5초라 전체 약 10분(병렬화 가능). 모자, 긴 머리, 망토는 hair_back/hair_front처럼 뷰별 레이어 소속 규칙이 필요하다.
- **조명 일관성**: 그림자/AO가 마네킹 기준으로 구워지므로 옷끼리의 차폐(두꺼운 외투 위 머리 그림자 등)는 shade 레이어 근사에 의존한다. 파츠가 마네킹에서 많이 떨어질수록 오차가 커진다. 모자는 shade_hat이 필요하다.
- **대안**: 런타임 WebGL 복셀 렌더러로 브라우저에서 조합마다 한 번 굽고 캐시하면 레이어 근사 문제가 사라지고 각도·프레임도 자유롭다. 다만 빌드 도구 없는 바닐라 JS 원칙 안에서 셰이더를 직접 써야 하고 저사양 기기 확인이 필요하다.
