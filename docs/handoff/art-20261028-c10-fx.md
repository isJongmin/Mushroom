## 1. 빌드
```
python3 assets/_src/fx/build.py            # 아이콘 6 + 구슬 시트 + 속성 베기 3 + mob manifest 갱신 (약 2초)
python3 assets/_src/fx/build.py --check    # 같은 코드의 기본 팔레트가 slash.png와 픽셀 단위로 같은지 확인(차이 0)
python3 assets/_src/fx/preview.py OUT_DIR  # icons.png, orbs.png, slashes_light.png, slashes_dark.png
```
- 원본은 `assets/_src/fx/`에 있다. `spec.py`는 규격, 버프 5종(`BUFFS`)과 드롭 종류 순서(`ITEMS` = BUFFS + heal), buffDrop 값, manifest fx 항목을 담은 데이터이고, `fx.py`가 그림을 그린다. 그 밖에 `build.py`, `preview.py`가 있다. 래스터라이저는 `art2d_mob/vec.py`를 그대로 쓴다(Pillow + numpy, 4배 슈퍼샘플). 글로우는 numpy 가우시안이다.
- 결정적이다. 두 번 빌드해서 md5가 같은 것을 확인했다.
- `art2d_mob/build.py`도 고쳤다. INFO의 drops를 지우고, manifest를 쓸 때 `fx/spec.py`의 buffDrop과 fx 항목을 같이 쓴다. 그래서 몬스터를 다시 빌드해도 manifest가 되돌아가지 않는다. 두 빌드가 만드는 manifest가 바이트 단위로 같은 것을 확인했다.

## 3. 아이콘 (`buffIcons`)
- 경로는 `assets/fx/buff/<id>.png`다. 기준점 없이 중앙 정렬로 쓴다. HUD에서 32~40px로 줄여 표시해도 읽힌다(36px 축소본으로 확인).
- 배지 색과 글리프(흰색에 진한 같은 계열 외곽선):

| id | 색 | 글리프 |
|---|---|---|
| range | 초록 #3EC27C | 양방향 굵은 화살표 |
| multi | 파랑 #4A84F4 | 대각선 칼날 자국 3개 |
| element | 보라 #9C66E8 | 불꽃(주황), 물방울(하늘), 번개(노랑) |
| power | 빨강 #EE4A48 | 검 + 노란 위쪽 화살표 |
| speed | 호박 #FFB01E | 큰 번개 + 속도선 3개 |
| heal | 민트 #2FD0B0 | 흰 십자 + 분홍 하트(오른쪽 아래) |

- heal은 버프가 아니므로 HUD에 표시하지 않는다. 아이콘은 줍기 알림 같은 곳에 필요하면 쓴다. 민트는 range 초록보다 푸른 쪽이라 나란히 놓아도 구분된다(36px에서 확인).

- 원형 게이지는 프런트가 배지 바깥(반지름 32 이상)에 그리면 겹치지 않는다. 스택 수 숫자는 오른쪽 아래에 두기를 권장한다.

## 4. 드롭 구슬 (`buffOrb`)
- 프레임 i는 `order[i]`의 종류다(0~4 버프, 5 heal). 프런트는 drop payload의 `buff` 값으로 order에서 인덱스를 찾으면 된다. anchor (24,24)는 구슬 중심이다. 구슬 지름은 약 28px(월드 약 19, 밀도 1.5)이고, 그 바깥은 글로우가 프레임 가장자리까지 이어진다.
- 색은 아이콘과 같고, 구슬 안에 아이콘 글리프를 축소해 넣었다. 반짝이 2개도 그림에 들어 있다. 정적 이미지이므로 위아래 흔들림은 프런트가 처리한다. 좌우 반전하지 않는다.
- 바닥에 놓을 때는 구슬 중심을 지면 위 월드 약 14~18에 두고 흔들림 폭을 약 3으로 하기를 권장한다.

## 5. 속성 베기 (`slashFire`, `slashIce`, `slashBolt`)
- `fx.slash`와 규격이 같다. frame 150x135, anchor (24,128)는 공격자 발 위치다. 2프레임 16fps이고, 오른쪽 공격이 기준이며 왼쪽은 좌우 반전한다. 호 모양은 slash.png와 픽셀 단위로 같고 색만 다르다. 속성색이 잘 보이도록 호 둘레에 약한 글로우를 더했다(프레임 안에 들어감).
- 매핑: `el` 1이면 slash_fire(불 주황), 2면 slash_ice(얼음 하늘색), 3이면 slash_bolt(번개 노랑), 0이면 기존 slash.png다. manifest 항목에 `element` 숫자를 같이 적어 두었다.

## 6. manifest 변경 (`assets/mob/manifest.json`)
- mobs 각각에서 `drops`를 지웠고 `buffDrop`을 추가했다. 값은 snail 0.35, bat 0.4, mushroom 0.45, slime 0.5, golem 1.0이다. golem에는 `buffDropCount: 2`도 추가했다. buffDropCount가 없으면 1개로 처리하면 된다.
- `dropBag`는 그대로 남겼다. fx에는 기존 `slash`와 함께 `buffOrb`, `buffIcons`, `slashFire`, `slashIce`, `slashBolt`를 추가했다. 나머지 키(ghost, tombstone, 몬스터 수치와 시트)는 바뀌지 않았다.

## 7. 확인
- 미리보기는 1x, 3x, 36px 축소본을 밝은 배경과 어두운 배경에서 각각 확인했다. 확인 후 고친 것은 세 가지다. 글리프 그림자를 줄였고(multi가 겹쳐 보이던 문제), 속도선을 끝이 가늘어지는 모양으로 바꿨고, 구슬 글리프 크기와 글로우를 키웠다.
- 한계: 밝은 배경에서는 구슬 글로우가 약하게 보인다(구슬 본체 색으로 구분된다). 복셀 맵 위에 합성한 화면은 아직 보지 못했다.
