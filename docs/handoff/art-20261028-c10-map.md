## 2. 빌드 / 검사 / 미리보기

```
python3 assets/_src/map_canva/build.py --install      # assets/map/ 에 쓰고 옛 clouds/far/mid.webp 삭제
python3 assets/_src/map_canva/build.py --out DIR      # 다른 폴더에 (src 경로는 assets/map/)
python3 assets/_src/map_canva/check.py [MAPDIR] [--determinism]
python3 assets/_src/map_canva/preview.py MAPDIR OUTDIR [--k 1.0]
```

원본 파일 (`assets/_src/map_canva/`)

| 파일 | 내용 |
|---|---|
| `panels.py` | **정본**. 패널 표: 파일, 지면 행, 발판, 로프, 스폰, 겹침, 보호/숨김 사각형, 자르기. 모두 원본 px 기준이다. 상수 UPSCALE 1.25, OVERLAP 120, EDGE_FADE 90, ROPE_REACH 15 |
| `build.py` | 빌드 (아래 처리 순서) |
| `check.py` | 검사 |
| `preview.py` | 미리보기 |
| `orig/{left,center,right}.png` | 원본 각 1776x896 |

빌드 처리 순서
1. 패널마다 1.25배로 키운다(LANCZOS).
2. 지면 행(세 패널 모두 790px, 잔디 윗면 띠 780~797의 가운데)을 같은 높이로 맞춘다. 흙 단면 높이도 같아 보정은 필요 없었다.
3. 이음매를 섞는다.
   - 아래쪽 지면 소품 띠(지면 위 300px까지): 색 차이가 가장 작은 세로 경로(DP)를 따라 섞는다. 보호 사각형(발판, 지정한 나무와 섬)은 자르지 않게 큰 비용을 준다. 한 행에 12열까지 옮길 수 있다.
   - 위쪽 하늘과 원경: 겹친 구간 전체에 걸친 넓은 그라데이션으로 섞는다. 보호 물체는 물체 모양 마스크(채도, 어두움, 구멍 메움)로 자기 패널 그림을 그대로 둔다.
   - 두 영역 사이는 60px에 걸쳐 바뀐다. 오른쪽 패널 색은 겹친 구간 평균에 맞춘다(±10%, 600px에 걸쳐 감쇠).
4. 이음매에 가린 발판 구간은 manifest에서 잘라낸다. 그림 소유 패널 기준이고, 이번에 잘린 발판은 없다.
5. 맵 양 끝 90px은 옅게 마감하고, 그림 위에 하늘 212px을 덧붙이고, 로프를 그린다.

결정적이다(`--determinism` md5 2회 같음).

**left 패널 겹침**
- 오른쪽 600px(x 1176~)은 중앙 패널 왼쪽 600px을 다시 그린 것이다. 구도는 같고 모양만 조금 다르다(카페, 벚나무 섬, 가로등 섬이 겹친다).
- 겹침을 탐색한 결과는 600px, 세로 0이었다. 그래서 left를 x 1326에서 자르고(`xmax`) 중앙과 150px(원본) 겹쳐 섞었다.
- 겹친 구간의 가로등 섬은 `hide`로 감추고 중앙 그림을 쓴다. 중복된 left 발판 3개(가로등 섬, 벚나무 섬, 이끼 돔 턱)는 넣지 않았다.

**center|right**
- 서로 다른 그림이다(탐색 결과 일치 없음). 겹침은 120px(원본)이다.
- 중앙 오른쪽 끝 벚나무 섬은 나무까지 보호해 온전히 남겼다. 그 뒤로 right 패널의 침엽수 윗부분이 원경처럼 비친다.

## 8. 알려진 문제

- 이음매 1
  - 하늘에 아주 옅은 세로 띠가 있다(1:1에서만 보임).
  - 바로 왼쪽의 left 다리 아래 개울 구간은 지면 윗면이 약 15px(원본) 낮다. 원래 그림 그대로이고, 서는 선(800)은 같다.
- 이음매 2: 중앙 벚나무 섬 뒤로 right 침엽수 윗부분이 반쯤 비쳐 원경 나무처럼 보인다.
- 원본끼리 비슷한 상점(이끼 돔 카페)이 left(회색 돔)와 중앙(이끼 돔)에 반복된다. 원본 그림 그대로다.
- 패럴랙스 깊이감은 없다(그림 한 장).
- 로프 몇 개는 건물 앞을 지나 내려온다(c-rope-bench는 테라코타 돔 앞, l-rope-bench는 회색 돔 앞). 위아래 발판에 닿게 하려면 피할 수 없었다.
- 프런트 할 일
  - 로프 매달리기(계약대로).
  - 월드 값(3840/888/800)을 manifest에서 읽기. world.js는 이미 그렇게 한다.
  - clouds/far/mid가 없는 manifest. 기존 동작으로 충분하다.
