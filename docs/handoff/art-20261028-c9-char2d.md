날짜: 2026-10-28 / 담당: 아트
상태: **미설치.** 빌드 결과는 `assets/_src/art2d/out/`에만 있다. `assets/avatar/`는 건드리지 않았다. 사용자 확인 후 메인 지시가 오면 `install.py`를 실행한다. commit은 하지 않았다.

## 1. 방향
- v1(메이플풍 2.5등신, 굵은 외곽선)은 "유치하다"는 피드백을 받아 폐기했다. 백업은 저장소 밖 `scratchpad/art2d_chibi_backup/`에 있다.
- v2: 약 4.2등신(두개골 기준), 가는 아몬드 눈(하이라이트 1개), 짧은 선 코, 작은 입, 은은한 볼터치. 외곽선은 1.15px이고 각 색의 어두운 톤이다. 채도를 낮춘 팔레트(오트밀, 크림, 차콜, 세이지, 더스티 블루, 머스타드, 테라코타)에 셀 셰이딩 2단(바탕 + 그늘 초승달)을 썼다. 머리카락은 정수리에서 뻗는 가닥(잎 모양)을 겹친 레이어드 컷이다.
- 방식: Python + Pillow + numpy. 베지어/캣멀롬 폴리곤을 4배 슈퍼샘플해 박스 평균으로 줄인다. 결정적이다(재빌드 211개 파일의 해시가 일치함).

## 3. 납품 규격 (`out/avatar/` -> 설치 후 `assets/avatar/`)
- 시트: 13프레임, 1872x192. 프레임 144x192, 기준점 (72,180), 밀도 1.5. 순서는 `front, front_b, side, walk0..3, back, jump, fall, prone, attack0, attack1`.
- animations: 기존 키 + `attack` [11,12] 120ms. `prone` [10].
- 키: 서 있을 때 머리끝이 y 8~16(모자 포함)이다. 정면 머리 맨 위는 월드 108~115.3이다.
- layerOrder (19개, 앞이 아래):
  `hair_back, hat_back, top_back, skin_far, shoes_far, bottom_far, top_far, skin, shoes, bottom, top, head, face, shade_hair(atop), hair_front, shade_hat(atop), skin_near, top_near, hat`
  - `*_far`: 옆 보기의 먼 팔/다리. `*_near`: 가까운 팔. 머리 위로 든 팔은 그 프레임에서 `*_far`에 넣었다(머리 뒤로 간다).
  - `head`(skin 파츠)는 옷 위에 그린다(후드, 칼라가 턱 밑으로 들어감).
  - 신발은 하의 아래에 그린다. 그래서 `shoes_under`와 `shade_top`은 없앴다.
  - 필수 레이어(`skin, face, hair_front, top, bottom, shoes, hat`)는 모든 id에 파일이 있다. 프런트 `REQUIRED_LAYERS`는 그대로 쓰면 된다.
- 파츠: 기존 id를 전부 같은 순서로 유지했다. 드롭 전용 10종은 `"drop": true`이고 메인이 고정한 id 그대로다.
  `hat:snail-shell`(소용돌이 패턴 버킷햇 + 더듬이), `hat:mushroom-cap`(물방울 주황 베레모), `hat:golem-helm`(돌 꽈배기 니트 비니 + 이끼 접단 + 새싹 핀), `top:slime-hood`(젤리 후드티), `top:bat-cape`(박쥐 날개 차콜 상의), `top:golem-armor`(돌 퀼팅 조끼 + 세이지 터틀넥), `bottom:mushroom-shorts`, `bottom:slime-pants`, `shoes:snail-boots`, `shoes:bat-boots`.
- 아이콘: `assets/avatar/icon/<파츠 키>/<id>.png`, 64x64 투명, 62개(hat none 제외 전부). 드롭 파츠도 포함이다.
- 용량: 3.4MB.
