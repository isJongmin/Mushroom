# art -> main/front: 사이클 9 배경 맵 (2D 메이플풍)

날짜: 2026-10-28 / 담당: 아트(맵)
상태: **납품**. 계약: ARCHITECTURE "사이클 9 계약"(월드 4800x1000, 지면 y=900, spawns), "사이클 8 계약"(platforms, 한 방향 통과).

## 1. 빌드 / 검사 / 미리보기

```
python3 assets/_src/art2d_map/build.py [--only ground,mid] [--jobs 2]   # 전체 약 2분(2코어)
python3 assets/_src/art2d_map/check.py [--determinism]
python3 assets/_src/art2d_map/preview.py OUTDIR [--platforms]
```

- 원본 `assets/_src/art2d_map/`: `vec.py`(베지어/다각형 → 4배 슈퍼샘플 래스터, 타일 렌더, 결정적), `geom.py`(도형), `pal.py`(재질 톤, 외곽선은 재질의 진한 톤), `props.py`(구름, 나무, 버섯 집, 풀, 꽃, 돌, 덩굴, 밧줄, 울타리, 가로등, 우물 등), `layers.py`(레이어 장면, 발판 그림), **`platforms.py`(정본: PLATFORMS, SPAWNS, SPAWN)**.
- 스타일: 진한 색조 외곽선(약 2.5px), 셀 셰이딩 2단 + 하이라이트, 빛은 왼쪽 위. 원경일수록 대기색(#CDEBFA)을 섞는다(mid 28%).
- check.py: manifest와 정본 일치, 층 간격 85~95, 층 수 4~5, 일반 발판 도달성(아래 층에서 점프 105, 가로 70 이내), 슈퍼 전용 발판(일반 점프 불가, 슈퍼 225 가능), 그림 대조(발판만 렌더해 윗면 첫 불투명 행 = y*1.5 ±1.5px가 열의 85% 이상, 서는 선 위로 솟는 장식은 제외), 좌우 끝 ±10px, ground.webp 서는 선+2 행 불투명, 지면선 전 구간 불투명, 스폰 규칙, 용량, md5 결정성. 결과: 전체 OK.
- 옛 복셀 맵 원본 `assets/_src/voxel_map/`은 손대지 않았다(사이클 9 계약상 삭제 가능, 메인 판단).

| clouds.webp | 0.10 | 0 | 3600x780 | 2400x520 | true |

| mid.webp | 0.55 | 480 | 4500x660 | 3000x440 | true |

- 합계 약 1.1 MB(한도 10 MB). 세로 parallax는 없다(프런트 drawLayer 그대로, y - camY).
- ground: 지면 윗선(외곽선 윗끝) = 1350px = 월드 900, 그 아래는 잔디 가장자리 + 흙 단면(지층, 묻힌 돌) 끝까지 불투명. 위쪽은 투명(발판, 집, 나무만).
- manifest 새 키: `height` 1000, `spawn` {x:2400, y:900}, `spawns`.

## 3. 발판 (월드, y = 서는 높이, 그림의 외곽선 윗끝 = y)

층: 지면 900 → 810 → 720 → 630 → 540 → 450, 슈퍼 점프 전용 330(2개).
- 서쪽 들판(헤네시스): w1~w10 (grass 잔디 흙 발판, plank 나무 판자, w8 밧줄 흔들다리), `w-sky` 1460~1580 @330(슈퍼, w9에서).
- 마을(1640~3060): t1/t3 기둥 데크 @810, t2/t4 판자 @720, 중앙 계단 tc1 @810 → tc2 @720 → tc3 @630 → tc4 @540. 집 문과 창은 가리지 않는다.
- 동쪽 숲(엘리니아): e1~e10, 거대 나무 줄기에 걸친 판자 발판, e7 흔들다리, `e-sky` 3950~4070 @330(슈퍼, e5에서).
- 전체 표는 `assets/_src/art2d_map/platforms.py` / manifest `platforms` (30개).
- 흔들다리 난간, 기둥 머리, 풀잎, 금빛 버섯은 서는 선 위로 솟은 장식이다(캐릭터 뒤에 그려짐).

## 5. 프런트 참고
- `WORLD`(constants)의 width/groundY/height를 manifest 값(4800/900/1000)으로 맞춰야 한다. assets.js는 groundY가 다르면 경고만 낸다.
- 카메라가 세로로 따라갈 때 camY < 0이면 하늘 첫 행이 늘어나 채운다(기존 처리). 월드 아래(y>1000)는 보이지 않게 카메라를 제한하면 된다.
