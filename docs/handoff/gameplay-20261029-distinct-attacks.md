# 직업별 공격 방식과 이펙트 분리

기본공격을 포함한 16개 공격이 각각 다른 패턴·궤적·판정·아이콘을 사용한다. 추가 스킬의 3/7/15초 쿨타임은 유지한다.

| 직업 | 기본공격 | 스킬 1 | 스킬 2 | 궁극기 |
|---|---|---|---|---|
| 검사 | 짧은 전방 베기 | 시간차 교차 2연격 | 지면을 따라 이동·폭발하는 불꽃 검기 | 뒤쪽도 타격하는 회전 검기 4회 |
| 궁수 | 연속 화살 2발 | 서로 다른 3개 궤적의 부채꼴 화살 | 착탄 지점 반경 145 폭발 | 6개 구역에 시간차 화살비 |
| 마법사 | 이동하는 에너지 볼 | 가까운 적 위치에 발톱 2연격 | 전방 560 길이를 관통하는 번개 빔 | 적이 있는 4개 구역에 순차 낙뢰 |
| 도적 | 표창 2발 | 고속 3연속 표창 | 반경 105를 가르는 대형 회전 표창 | 3개 분신 위치에서 표창 9발 |

- `jobs.js`: 패턴·속도·분산·반경·설명과 고정 공격 수치.
- `attack-patterns.js`: 고정 월드 좌표의 지연 타격. 호스트만 피해를 적용하며 맵 전환/퇴장 때 모두 해제.
- `combat.js`: 실제 대각선 이동과 선분 충돌. 충돌 시 해당 투사체 제거. 착탄 확정에 skill을 포함해 올바른 폭발을 그린다.
- `skill-visuals.js`: 16개 아이콘·캐스팅·투사체·폭발을 개별 구현. 궤적, 발톱, 화염, 마법진, 전기 분기, 분신, 입자를 사용한다.
- 후속 기본공격이 이전 스킬의 이펙트나 지연 타격을 취소하지 않는다. 이펙트는 발동 좌표에 남고 캐릭터 이동을 따라가지 않는다.
- 예측 착탄 후 호스트 좌표가 도착하면 폭발 위치를 보정하며 중복 생성하지 않는다.

검증: Node 테스트 7종 통과. 실제 브라우저 local 모드에서 프로필→로비→방 입장, 썬더빔 발사, 매직클로/썬더스톰 동시 표시, 피해 숫자, 쿨타임 표시 확인. 실제 렌더러로 16개 공격 비교 장면을 확인했으며 게임 코드의 콘솔 오류 없음. 실 Supabase 세션의 다중 사용자 테스트는 수행하지 않음.
