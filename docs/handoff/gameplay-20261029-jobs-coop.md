# 협동 사냥과 직업 선택 (2026-10-29)

사용자 요청에 따라 검증이 끝나는 항목부터 main에 반영한다.

- 플레이어 공격의 PvP 피해·넉백 경로 제거. 몬스터 접촉 피해/사망/부활 유지.
- 실제 모자가 합성되는 프레임의 챙 아래로 헤어를 클리핑. 아래쪽 긴 머리는 유지하며 ribbon-pink는 제외. 헤어 단독 썸네일에는 모자 마스크 미적용.
- 몬스터 리스폰 8초 → 10초. 최초 개체 수와 구역별 최대 개체 수는 유지.
- 프로필에서 검사/궁수/마법사/도적 선택. `profile.job`을 브라우저에 저장하며 기존 프로필은 검사로 정규화. 로비의 꾸미기에서 변경 후 입장.
- 검사: 근거리 최대 3마리 베기. 궁수: 원거리 이동 화살 두 발. 마법사: 이동 마력탄과 최대 4마리 범위 폭발. 도적: 빠른 회전 표창 두 발.
- 공격 키 Ctrl/J/X와 모바일 공격 버튼 유지. 버프는 선택 직업의 기본 공격에 적용.
- 몬스터 피해는 호스트가 발사체의 이동 구간과 충돌을 계산. 공격 seq/발신 위치/정상 공격 간격을 검사. 접속 시각 기반 seq 초기값으로 재접속 후 이전 seq와 충돌 방지.
- 기존처럼 버프 수치는 공격자가 계산하고 수신자가 상한을 제한하는 구조. 서버 권위 전투로 변경한 것은 아님.

- `node tests/profile-jobs.test.mjs`: 네 직업 저장/복구, 기존·비정상 프로필 기본값, 10초 재생성 시뮬레이션.
