# 직업별 스킬 및 꾸미기 개편

- 기본공격은 별도 재사용 대기 없음. 240ms 공격 동작 간격으로 누르고 있으면 반복한다.
- 직업마다 추가 스킬 3개. 버튼 클릭 또는 숫자 1/2/3으로 사용, 각각 3/7/15초 재사용 대기.
- 검사: 파워 스트라이크 / 플레임 슬래시 / 드래곤 블레이드
- 궁수: 트리플 샷 / 폭발 화살 / 피닉스 애로우
- 마법사: 파이어 볼 / 프로스트 노바 / 썬더 스톰
- 도적: 트리플 스로우 / 섀도 스핀 / 팬텀 스타
- 스킬 버튼은 무기 실루엣과 단계 표시, 회색 아이콘·차오르는 가림막·남은 시간(0.1초)을 제공한다.
- 공격 강화 드롭/획득 효과 폐지. 회복 드롭만 25% 확률로 생성하며 자동 획득한다. 줍기 버튼과 Z 단축키 제거.
- 공격 패킷에 skill(0~3) 추가. 수신 측에서 고정 수치를 다시 계산하고 스킬별 쿨타임, 순서 번호, 공격 원점을 검증한다.
- 꾸미기 직업 선택은 독립된 전체 너비 영역. 데스크톱 4열 / 모바일 2열.
- 직업 변경 시 측면 기본공격 프레임과 직업별 무기/이펙트를 650ms 재생한다.

검증: jobs, profile-jobs, projectiles-respawn, map-protocol, areas, wardrobe-loader Node 테스트. 브라우저 실행 파일이 없어 실제 화면 캡처와 실시간 서버 연결 검사는 수행하지 못함.
