# 궁극기 연출·피해 강화

기존 1초 남짓한 일반 공격 이펙트 대신, 직업별 궁극기에 2.8~2.9초의 독립된 시퀀스를 적용한다. 15초 재사용 대기와 이동·다른 공격 사용은 유지한다.

| 직업 | 예고/소환 | 연속 공격 | 마무리 |
|---|---|---|---|
| 검사: 천검 · 라스트 저지먼트 | 여섯 천검과 지면 봉인진 | 600/850/1100ms 회전 검격 | 1500ms 거대 대검 3연타 + 1800ms 충격파 |
| 궁수: 피닉스 · 아스트랄 레인 | 깃털이 겹치는 불사조와 천공 마법진 | 700ms부터 여섯 구역에 화살 폭격 | 1740ms 불사조 강림 3연타 |
| 마법사: 썬더 갓 · 제로 아워 | 다중 봉인진·룬·공전 수정 | 650ms부터 적 구역에 네 번의 낙뢰 | 1740ms 거대 번개 기둥과 분기 번개 3연타 |
| 도적: 팬텀 · 이클립스 | 초승달과 다섯 의식 분신 | 세 발사 위치에서 480ms부터 표창 아홉 발 | 1660ms 거대 처형 검격 4연타 |

- 궁극기 피해 배율과 총 타수를 강화: 검사 7타, 궁수 9타, 마법사 7타, 도적 13타(투사체 9 + 마무리 4). 범위·궤적에 따라 실제 적중 타수는 달라진다.
- 별도 `ultimate-visuals.js`에 곡선으로 그린 무기/불사조/분신, 다중 광선, 룬, 파편, 잔광을 구현. 대량 비트맵과 외부 이미지 의존성을 추가하지 않는다.
- 전용 궁극기 이름 배너, 가장자리 음영, 마무리 순간 최대 가로 6/세로 3.5 CSS px의 짧은 카메라 충격. 화면 전체를 반복 점멸시키지 않는다.
- 동작 줄이기 설정에서는 카메라 충격과 배너 이동을 끈다. 배너는 DPR을 고려한다.
- 일반 스킬에도 발동 마법진·광택을 보강하고 궁극기 버튼을 전용 문양·금색 프레임으로 구분한다.
- 기본공격이 많아도 재생 중인 궁극기가 메모리 상한에서 먼저 제거되지 않도록 한다. 화면 밖 연출은 그리지 않는다. 맵 전환/퇴장 시 모든 예약 타격·카메라 충격이 해제된다.

검증: Node 회귀 테스트 8종, JavaScript 문법과 diff 검사 통과. 브라우저 local 모드에서 검사 궁극기 발동/배너/쿨타임 확인. 실제 렌더러로 네 직업의 소환·마무리 프레임 확인, 게임 코드의 콘솔 오류 없음. 실제 Supabase 다중 사용자 연결은 미검증.
