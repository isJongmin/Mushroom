# 일반 공격·스킬 스타일 개선 및 기본공격 속도 조정

기본공격과 추가 스킬 1·2, 총 12종의 아이콘·발동·투사체·명중 연출을 개선한다. 궁극기는 기존 전용 렌더러를 사용하며, 이전 버전과 Canvas 그리기 명령 비교로 동일함을 검증했다.

- 검사: 금속 검날, 얇고 끝이 날카로운 검기 리본, 교차 검격, 다층 불꽃 검기와 파편.
- 궁수: 금속 화살촉과 깃털, 세 방향 궤적, 회전 문양으로 감싼 폭발 화살과 착탄 조각.
- 마법사: 궤도 문양이 도는 에너지볼, 곡선형 발톱 자국, 응축 코어·회전 렌즈·파형이 있는 썬더빔.
- 도적: 금속 재질의 갈고리 표창, 시간차 잔상, 일곱 날이 분리되어 보이는 회전 표창과 절삭 잔광.
- 일반 연출은 전용 배너/암전/화면 흔들림을 추가하지 않는다. 주변 광원 반경은 최대 80, 입자는 한 번에 최대 16개로 제한. 화면 밖 투사체/착탄은 그리지 않되 시뮬레이션은 유지한다.

기본공격 간격은 240ms에서 360ms로 조정한다. 초당 약 4.17회에서 2.78회로, 연사 속도가 약 33% 줄어든다. 스킬 쿨타임 3/7/15초와 피해·충돌 방식은 유지한다. 받는 쪽 공격 빈도 검증도 같은 상수를 사용한다. 기본공격 모션은 마지막 발동 시각을 기준으로 360ms에 한 번 재생하여 누르고 있을 때 첫 프레임이 중간에 반복되지 않게 한다.

검증: Node 테스트 9종 통과, 전체 변경 JavaScript 문법/diff 검사 통과. 궁극기 4직업×양방향×8시점, 아이콘·분신 투사체·명중의 기존 Canvas 명령과 동일성 비교 통과. 브라우저 local 모드에서 프로필/입장/스킬 버튼/기본공격 연사와 12개 공격·착탄 장면 검증, 게임 코드 콘솔 오류 없음. 실제 Supabase 다중 사용자 연결은 미검증.
