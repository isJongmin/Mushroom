# 2D 모바일 HUD 정리

3D 클라이언트/렌더러/전용 테스트/진입 링크를 제거했다. 기존 `3d.html`은 2D `index.html`로 연결하는 호환 주소만 유지한다. 기존 2D 프로필·장비·펫 저장 키와 데이터는 변경하지 않는다.

메이플스토리M 공식 앱 소개 및 화면 구성을 참고해 상태/탐색/전투/관리 영역을 나눴다. 외부 게임의 아이콘이나 그래픽을 복제하지 않고 기존 캐릭터·스킬 아트를 사용한다. 참고: https://apps.apple.com/kr/app/id1133463693

- 좌측 상단: 실제 캐릭터 초상, 닉네임, 현재/최대 HP. 바로 아래 지역·골드와 가방 버튼.
- 우측: 접이식 미니맵과 메뉴. 나가기·방 삭제·채팅·기록을 메뉴 안으로 옮겼다. 채팅 기록은 기본 접힘이며 명시적으로 저장한 펼침 설정은 유지한다.
- 모바일 전투: 왼쪽 방향키/엎드리기, 오른쪽 점프/큰 기본 공격/원형 스킬 3개. 같은 버튼 노드를 재배치하므로 기존 멀티터치 입력과 쿨타임을 유지한다.
- 전체 화면 캔버스 위에 반투명 조작부를 배치한다. 카메라 기준 높이는 엄지 영역을 제외해 지면의 캐릭터가 조작부 뒤로 내려가지 않게 한다. 캔버스 아래 여유 영역은 지면 끝 픽셀을 연장해 빈 하늘 띠가 생기지 않게 한다.
- 세로 휴대폰, 가로 휴대폰, 터치 태블릿을 같은 뷰포트 규칙으로 분류한다. 채팅을 열면 조작부를 숨기고 키보드에 따라 `visualViewport` 높이를 적용한다. 닫기 버튼으로 즉시 전투로 돌아올 수 있다.
- 로비는 모바일 배너를 줄이고, 최초 꾸미기에서 반복 소개 배너를 숨겼다. 주변 페이지도 게임과 같은 청회색/아이보리 색으로 맞췄다.

검증: `node tests/game-layout.test.mjs`, 기존 무기 전환/인벤토리/일괄 합성/성장 테스트. 브라우저에서 실제 로컬 방의 세로/가로 레이아웃, 메뉴, 미니맵, 가방, 채팅 열기·닫기를 확인한다. 멀티플레이 서버 로직과 전투 판정은 이번 변경 범위에 포함하지 않는다.
