# 지역 NPC, 이단 점프 착지, 사냥 목표

## 착지 원인과 수정

실제 room 화면은 areaMap의 원본 발판 목록을 physics에 넘겼다. 이 목록은 높이순이 아니며 보조 발판도 뒤에 추가된다. crossed 함수는 높이순이라는 전제로 첫 번째 낮은 발판을 보고 탐색을 중단해 위층 착지를 놓쳤다. 이전 world-expansion 테스트는 normalizePlatforms를 거친 목록으로 검사했기 때문에 실제 경로와 달랐다.

- crossed는 입력 순서와 관계없이 통과한 가장 높은 발판을 선택한다.
- 초기 로딩과 지역 변경 모두 normalizePlatforms/normalizeRopes를 사용한다.
- 위층 발판 착지 시 점프 누름을 다음 입력까지 억제해 누르고 있던 버튼 때문에 즉시 재도약하지 않는다.
- 슈퍼점프 속도는 1120으로 소폭 보완했다. 단독 상승 높이 약 314로 305 간격도 통과한다.
- 실제 두 번의 입력과 원본 순서의 발판을 함께 사용해 120/60/30/20Hz에서 착지·유지를 검증한다. 빠른 낙하로 여러 발판을 지날 때도 위층을 우선한다.

## 조사와 선택

메이플스토리 공식 가이드는 연속 사냥 콤보/멀티킬 보상과 룬으로 단조로운 사냥에 단기 목표·변화를 제공하는 구조를 설명한다.

- https://gi.maplestory.nexon.com/Guide/Contents/FieldHunt
- https://maplestory.nexon.com/Guide/N23GameInformation/Articles/454

이 게임은 경험치 대신 장비·골드로 성장하므로 콤보 보상을 골드에 연결하고, 현재 무기 종류의 장비를 받는 반복 사냥 의뢰를 추가했다. 아래 수치는 본 게임의 자체 설계이며 원작 수치를 복제한 것이 아니다.

### 콤보

같은 지역에서 20초 안에 처치 참여를 이어가면 콤보가 증가한다. 5콤보마다 해당 처치 골드가 5% 증가하며 최대 30%다. 개인별로 호스트가 계산하고 드롭 패킷에 반영한다. HUD는 최근 획득 콤보를 5초간 표시한다. 지역 이동·호스트 변경 시 초기화되며 별도 영구 기록은 만들지 않는다. 보상 영수증 중복 방지 경로를 유지한다.

### 지역 사냥 의뢰

지역별 처치 참여 20회마다 자동 완료한다. 버섯/광산/이끼/서리는 각각 고급/희귀/영웅/전설의 **현재 장착 무기 종류** 장비 1개와 150/450/1350/4050 G를 추가로 바닥에 떨어뜨린다. 장비와 골드는 기존 줍기/펫 경로를 이용한다. 진행은 기존 지역별 kills에 저장되어 접속을 다시 해도 이어진다. 방어 이벤트 성공 보상 패킷 자체는 처치 횟수를 올리지 않는다. 기존 저장 kills는 그대로 이어 쓰며 이전에 달성한 20회 단위 보상을 소급 지급하지 않는다.

일반 전리품과 의뢰 보상, 진행 카운트는 같은 저장 명령에서 원자적으로 처리한다. 영수증 중복으로 재지급되지 않으며 바닥 드롭 용량이 부족하면 카운트도 증가하지 않는다. 기존의 호스트/브라우저 저장 경제를 유지한다.

## 검증

npc-hunt-landing 테스트는 8명 외형 검증, 정렬되지 않은 발판과 실제 이단 입력, 착지 후 버튼 유지, 콤보 개인 분리·시간 만료·상한, 네 지역 의뢰 보상·영속성·중복 방지·실패 롤백·네트워크 필드 검사를 포함한다. 기존 지역 확장, 장비 성장, 인벤토리, 보스 및 네트워크 테스트도 실행했다. 브라우저의 사냥 보상 검증은 테스트용 처치 이벤트를 사용하며 실제 몬스터 20마리 전투 완주와 구분한다.

실제 모바일 점프 버튼의 두 번 클릭으로 광산 수정 발판(y=495)에 착지·유지되는 것을 브라우저 상태와 화면으로 확인했다. 의뢰 완료는 채팅과 짧은 HUD 배너로 알린다.
