### 2-1. 항목 12 미검증 사유
- IME 조합 중 Esc 무시 (한글 입력 조합 중 Esc가 모달을 닫지 않는지) 는 헤드리스 키 입력으로 재현하지 못함. 실기 확인 필요.
- Safari 15.4 미만의 `inert` 대체 경로 (포커스/인터랙션 차단 방식) 는 Chromium 한 종류에서만 확인. 구형 Safari 실기 확인 필요.

### 2-2. 항목 20 미검증 사유
- 리스너 개수는 DOM/브라우저 API로 셀 수 없음. 타이머, rAF, BroadcastChannel, `.screen` 수는 로비 기준값과 같음을 확인.
- JS 힙 증가는 DevTools 없이 측정하지 않음. 필요하면 DevTools 힙 스냅샷을 수동으로 확인.

### 2-3. 항목 30 미검증 사유
- 정적 검사 (권한, RLS, RPC 반환 타입, password_hash 노출 등) 는 마이그레이션 파일 기준으로 통과.
- 실제 Supabase 적용 확인은 하지 않음: (1) 배포 설정 (Allow public access 끄기, 익명 로그인 켜기), (2) 실제 DB에서 RLS 우회 시도, realtime.send의 RLS 통과 여부. 운영 DB 접근이 필요해서 로컬 QA 범위 밖.
