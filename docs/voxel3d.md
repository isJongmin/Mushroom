# 버섯마을 3D 첫 버전

진입: `3d.html`. 기존 2D 게임의 꾸미기/로비에서 3D 버전 링크로 이동할 수 있다. 기존 방 안에서는 링크를 숨겨 터치 전투 버튼을 가리지 않는다.

## 범위

- 완전한 3D 좌표, 원근 카메라, 자유 이동/점프, 드래그 회전/휠 줌.
- 복셀 지형, 나무, 주택, 우물, 상점, NPC, 포탈. 기존 `ground()` 단위 격자를 그리디 메시로 합쳐 지형 인스턴스 수를 줄였다.
- 검/활/스태프/아대의 공격 방식과 세 가지 스킬, 등급에 따른 해금, 공유 슬롯 쿨타임.
- 추적/배회/피격/리스폰 몬스터, 플레이어 위치를 예고한 후 도약/착지하는 버섯왕.
- 세 지역: 버섯마을→광산마을→이끼마을. 기존 장비 등급 해금 규칙을 적용한다.
- 장비 드롭·근처 자동 수집·가방·일괄 합성·다중 판매, 루루의 지역 펫 뽑기와 동행 보너스.
- WebGL2 instanced drawing. GPU 컨텍스트를 만들 수 없는 브라우저에서는 동일한 3D 지오메트리를 Canvas 원근 투영으로 그린다. 호환 렌더러는 WebGL보다 표현과 성능에 제한이 있다.

## 조작

WASD/방향키 이동, Space 점프, J 기본 공격, K/L/; 스킬, E NPC/포탈 상호작용, B 가방. 무기 버튼은 보유한 해당 종류 중 최고 등급을 착용한다. 모바일은 왼손 조이스틱, 오른손 점프/공격/스킬과 화면 드래그를 사용한다.

## 저장과 기존 게임 보호

싱글플레이, 별도 저장 키 `mushroom:voxel3d:v1:equipment-v1`. 기존 `createProgressionStore`의 IndexedDB 거래로 장비/재화/펫을 저장한다. 최초에 검과 다른 세 종류 무기를 지급하며 지급 기록으로 중복을 방지한다. 2D 캐릭터/장비/방 데이터는 읽거나 변경하지 않는다. 3D 마을 위치/몬스터/처치 표시 수는 세션 데이터다. 장비·펫 등 성장 데이터는 유지된다.

블록 채굴/설치, 건축, 1인칭, 3D 멀티플레이 동기화는 포함하지 않는다. 현재는 새 3D 클라이언트와 전투/성장 흐름을 검증하는 버전이다.

## 검증

`node tests/voxel3d.test.mjs`: 카메라 행렬, 세 지역·네 무기·다섯 등급 지오메트리, 지형 메시 수 예산, 벽 관통 방지, 근접 공격 방향, 안전한 리스폰, GPU 없는 환경의 원근 렌더링.

기존 성장/인벤토리/일괄 합성 테스트도 실행한다. 브라우저에서는 호환 렌더러로 마을 표시·이동·활 처치·가방과 모바일 배치를 확인한다. 검증 브라우저는 WebGL2를 제공하지 않아 GPU 렌더링의 실제 장치 성능 검증은 별도로 필요하다.
